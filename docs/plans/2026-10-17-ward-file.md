# The Ward File Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-with-review to implement this plan task-by-task.

**Goal:** Every ward lives in one encrypted `.wardplanning` file in app data, sealed to the
devices its access list holds and read strictly, and `WardSession` saves the document with
this device's own state beside it in one write after every change; the app opens wards from
a list instead of file paths, is named Ward Planning, states its version once, and runs one
instance per user.

**Architecture:** `WardFile` writes and reads the format: a one-line JSON header whose exact
bytes are the associated data of an XChaCha20-Poly1305 payload, the data key sealed with
`crypto_box_seal` to every device and open invite, and a `qCompress`ed JSON payload with the
parts `ward`, `access`, `landed` and, in a local file only, `device`. `JsonReader` makes every
reader strict. `Identity` holds the device's two keypairs, derived from the two secrets the key
file holds, and its fingerprint. `WardSession` saves and opens through a `WardStore` of bytes,
which the app backs with `FileWardStore` in app data's `wards` folder and tests back with
`FakeWardStore`. Push, fetch, landed-mark trimming, access-list commands, rotation and
invitations are plan 3; this plan defines and carries their fields.

**Tech Stack:** Qt 6.11 (Core, Gui, Widgets, Test), C++17, MSVC 2022, CMake + Ninja via
`build.bat`, libsodium 1.0.22 from vcpkg, Qt Test; `tests/spec` uses nlohmann-json, zlib and
libsodium without Qt.

**Design authority:** `docs/SHARED_WARD_DESIGN.md`. Section names in *italics* are its
sections. This plan builds on `docs/plans/2026-10-17-commands-and-replay.md` (plan 1) as its
last task leaves the code.

```cpp
#pragma once

#include <QByteArray>
#include <QString>
#include <optional>

/// Base64url without padding: the encoding of every binary value in a ward file, the key
/// file and the wire.
class Base64Url
{
public:
    static QString encode(const QByteArray& bytes);

    /// The bytes text encodes, when text is exactly the unpadded base64url encoding of length
    /// bytes. Padding, characters outside the base64url alphabet, a different length and
    /// non-zero unused trailing bits are each refused, so every value has one spelling.
    static std::optional<QByteArray> decode(const QString& text, int length);
};
```

### `src/services/Base64Url.cpp`

```cpp
#include "Base64Url.h"

QString Base64Url::encode(const QByteArray& bytes)
{
    return QString::fromLatin1(bytes.toBase64(QByteArray::Base64UrlEncoding | QByteArray::OmitTrailingEquals));
}

std::optional<QByteArray> Base64Url::decode(const QString& text, int length)
{
    QByteArray::FromBase64Result result = QByteArray::fromBase64Encoding(
        text.toLatin1(),
        QByteArray::Base64UrlEncoding | QByteArray::AbortOnBase64DecodingErrors);
    if (!result || result.decoded.size() != length || encode(result.decoded) != text)
    {
        return std::nullopt;
    }
    return result.decoded;
}
```

Comparing the re-encoding with the text is what refuses padding, the standard alphabet and
non-canonical trailing bits, whatever Qt's decoder accepts on its own.

### `src/services/Crypto.h`

```cpp
#pragma once

#include <QByteArray>
#include <optional>

/// The libsodium calls the format makes, over QByteArray.
class Crypto
{
public:
    static constexpr int KeyBytes = 32;          ///< a data key, a public, secret or verify key, a seed
    static constexpr int NonceBytes = 24;        ///< an XChaCha20-Poly1305 nonce
    static constexpr int SealedKeyBytes = 80;    ///< a data key sealed with crypto_box_seal
    static constexpr int FingerprintBytes = 16;
    static constexpr int IdBytes = 16;           ///< a document id or a user id

    /// Initialises libsodium. Nothing else here may run until it has answered true.
    static bool initialise();

    /// count bytes from randombytes_buf.
    static QByteArray randomBytes(int count);

    /// Unkeyed BLAKE2b of input, length bytes long, with a zero salt and personalisation
    /// zero-padded to 16 bytes; an empty personalisation is all zeros.
    static QByteArray hash(const QByteArray& input, int length, const QByteArray& personalisation);

    /// message sealed to an X25519 public key with crypto_box_seal.
    static QByteArray seal(const QByteArray& message, const QByteArray& publicKey);

    /// What sealed holds, or none when it does not open with this keypair.
    static std::optional<QByteArray> unseal(const QByteArray& sealed, const QByteArray& publicKey, const QByteArray& secretKey);

    /// plaintext encrypted with XChaCha20-Poly1305 under key and nonce, authenticating
    /// associatedData: the ciphertext followed by its 16-byte tag.
    static QByteArray encrypt(const QByteArray& plaintext, const QByteArray& associatedData,
                              const QByteArray& nonce, const QByteArray& key);

    /// The plaintext, or none when the tag does not verify for this key, nonce and
    /// associatedData.
    static std::optional<QByteArray> decrypt(const QByteArray& ciphertext, const QByteArray& associatedData,
                                             const QByteArray& nonce, const QByteArray& key);

    /// The X25519 public key of a secret key: crypto_scalarmult_base.
    static QByteArray sealingPublicKey(const QByteArray& secretKey);

    /// The Ed25519 verify key of a seed: the public half of crypto_sign_seed_keypair.
    static QByteArray verifyKey(const QByteArray& seed);
};
```

### `src/services/Crypto.cpp`

```cpp
#include "Crypto.h"

#include <sodium.h>

static_assert(static_cast<int>(crypto_box_PUBLICKEYBYTES) == Crypto::KeyBytes);
static_assert(static_cast<int>(crypto_box_SECRETKEYBYTES) == Crypto::KeyBytes);
static_assert(static_cast<int>(crypto_sign_PUBLICKEYBYTES) == Crypto::KeyBytes);
static_assert(static_cast<int>(crypto_sign_SEEDBYTES) == Crypto::KeyBytes);
static_assert(static_cast<int>(crypto_aead_xchacha20poly1305_ietf_KEYBYTES) == Crypto::KeyBytes);
static_assert(static_cast<int>(crypto_aead_xchacha20poly1305_ietf_NPUBBYTES) == Crypto::NonceBytes);
static_assert(static_cast<int>(crypto_box_SEALBYTES) + Crypto::KeyBytes == Crypto::SealedKeyBytes);
static_assert(static_cast<int>(crypto_generichash_blake2b_PERSONALBYTES) == 16);

namespace
{

unsigned char* bytesOf(QByteArray& bytes)
{
    return reinterpret_cast<unsigned char*>(bytes.data());
}

const unsigned char* bytesOf(const QByteArray& bytes)
{
    return reinterpret_cast<const unsigned char*>(bytes.constData());
}

}  // namespace

bool Crypto::initialise()
{
    return sodium_init() >= 0;
}

QByteArray Crypto::randomBytes(int count)
{
    QByteArray bytes(count, '\0');
    randombytes_buf(bytesOf(bytes), static_cast<size_t>(bytes.size()));
    return bytes;
}

QByteArray Crypto::hash(const QByteArray& input, int length, const QByteArray& personalisation)
{
    Q_ASSERT(personalisation.size() <= static_cast<qsizetype>(crypto_generichash_blake2b_PERSONALBYTES));
    QByteArray personal = personalisation.leftJustified(crypto_generichash_blake2b_PERSONALBYTES, '\0', true);
    QByteArray output(length, '\0');
    crypto_generichash_blake2b_salt_personal(bytesOf(output), static_cast<size_t>(output.size()),
                                             bytesOf(input), static_cast<unsigned long long>(input.size()),
                                             nullptr, 0,
                                             nullptr,
                                             bytesOf(personal));
    return output;
}

QByteArray Crypto::seal(const QByteArray& message, const QByteArray& publicKey)
{
    QByteArray sealed(message.size() + crypto_box_SEALBYTES, '\0');
    int result = crypto_box_seal(bytesOf(sealed), bytesOf(message),
                                 static_cast<unsigned long long>(message.size()), bytesOf(publicKey));
    Q_ASSERT(result == 0);
    Q_UNUSED(result);
    return sealed;
}

std::optional<QByteArray> Crypto::unseal(const QByteArray& sealed, const QByteArray& publicKey, const QByteArray& secretKey)
{
    if (sealed.size() < static_cast<qsizetype>(crypto_box_SEALBYTES))
    {
        return std::nullopt;
    }
    QByteArray message(sealed.size() - crypto_box_SEALBYTES, '\0');
    if (crypto_box_seal_open(bytesOf(message), bytesOf(sealed), static_cast<unsigned long long>(sealed.size()),
                             bytesOf(publicKey), bytesOf(secretKey)) != 0)
    {
        return std::nullopt;
    }
    return message;
}

QByteArray Crypto::encrypt(const QByteArray& plaintext, const QByteArray& associatedData,
                           const QByteArray& nonce, const QByteArray& key)
{
    QByteArray ciphertext(plaintext.size() + crypto_aead_xchacha20poly1305_ietf_ABYTES, '\0');
    unsigned long long length = 0;
    crypto_aead_xchacha20poly1305_ietf_encrypt(bytesOf(ciphertext), &length,
                                               bytesOf(plaintext), static_cast<unsigned long long>(plaintext.size()),
                                               bytesOf(associatedData), static_cast<unsigned long long>(associatedData.size()),
                                               nullptr, bytesOf(nonce), bytesOf(key));
    Q_ASSERT(length == static_cast<unsigned long long>(ciphertext.size()));
    return ciphertext;
}

std::optional<QByteArray> Crypto::decrypt(const QByteArray& ciphertext, const QByteArray& associatedData,
                                          const QByteArray& nonce, const QByteArray& key)
{
    if (ciphertext.size() < static_cast<qsizetype>(crypto_aead_xchacha20poly1305_ietf_ABYTES))
    {
        return std::nullopt;
    }
    QByteArray plaintext(ciphertext.size() - crypto_aead_xchacha20poly1305_ietf_ABYTES, '\0');
    unsigned long long length = 0;
    if (crypto_aead_xchacha20poly1305_ietf_decrypt(bytesOf(plaintext), &length, nullptr,
                                                   bytesOf(ciphertext), static_cast<unsigned long long>(ciphertext.size()),
                                                   bytesOf(associatedData), static_cast<unsigned long long>(associatedData.size()),
                                                   bytesOf(nonce), bytesOf(key)) != 0)
    {
        return std::nullopt;
    }
    return plaintext;
}

QByteArray Crypto::sealingPublicKey(const QByteArray& secretKey)
{
    QByteArray publicKey(crypto_box_PUBLICKEYBYTES, '\0');
    crypto_scalarmult_base(bytesOf(publicKey), bytesOf(secretKey));
    return publicKey;
}

QByteArray Crypto::verifyKey(const QByteArray& seed)
{
    QByteArray verifyKey(crypto_sign_PUBLICKEYBYTES, '\0');
    QByteArray signingKey(crypto_sign_SECRETKEYBYTES, '\0');
    crypto_sign_seed_keypair(bytesOf(verifyKey), bytesOf(signingKey), bytesOf(seed));
    return verifyKey;
}
```

Recalled, and checked by `IdentityTest::keyFileSecretsGiveTheKnownKeysAndFingerprint`:
`crypto_box_keypair` makes its public key as `crypto_scalarmult_base` of 32 random secret

### `src/services/JsonReader.h`

```cpp
#pragma once

#include <QByteArray>
#include <QJsonArray>
#include <QJsonObject>
#include <QJsonValue>
#include <QList>
#include <QSet>
#include <QString>
#include <QStringList>
#include <memory>
#include <optional>

/// Reads one JSON object exactly as its writer wrote it. Every field is taken by its type: a
/// field missing, of the wrong type or malformed fails the read, and finish() fails it for
/// any field left untaken. A field its writer leaves out when empty is taken with an
/// optional... call, which reads its absence as empty and fails on an empty value written
/// out, since the writer never writes one.
///
/// Every fromJson that takes a JsonReader ends with finish(). A failure is shared with every
/// reader made from this one and the first one found is kept, with the path of the field it
/// names. A reader returns empty values once it has failed, so whoever reads a whole tree
/// asks failed() once, at the top.
class JsonReader
{
public:
    explicit JsonReader(const QJsonObject& object);

    /// The object bytes hold, or none when they are not one JSON object.
    static std::optional<QJsonObject> parseObject(const QByteArray& bytes);

    /// True for a JSON number with no fractional part, within the range a double holds exactly.
    static bool isInteger(const QJsonValue& value);

    bool failed() const { return !m_status->problem.isEmpty(); }
    const QString& problem() const { return m_status->problem; }

    /// The object as it was given, for a reader that keeps what it read as it is.
    const QJsonObject& source() const { return m_object; }

    /// Every key of the object, for an object whose keys are data.
    QStringList keys() const { return m_object.keys(); }

    QString string(const QString& key);
    QString optionalString(const QString& key);
    qint64 integer(const QString& key);
    std::optional<qint64> optionalInteger(const QString& key);
    double number(const QString& key);
    std::optional<double> optionalNumber(const QString& key);
    bool boolean(const QString& key);

    /// A flag its writer writes only when true.
    bool optionalFlag(const QString& key);

    /// Base64url of exactly length bytes.
    QByteArray bytes(const QString& key, int length);

    JsonReader object(const QString& key);
    std::optional<JsonReader> optionalObject(const QString& key);
    QList<JsonReader> objects(const QString& key);
    QList<JsonReader> optionalObjects(const QString& key);
    QStringList strings(const QString& key);
    QStringList optionalStrings(const QString& key);

    /// An array of base64url values of exactly length bytes each.
    QList<QByteArray> optionalBytesList(const QString& key, int length);

    /// The value under key, for a type that reads its own JSON value.
    QJsonValue value(const QString& key);

    /// Fails the read at key, unless it has already failed.
    void fail(const QString& key, const QString& what);

    /// Fails the read for the first field nothing took.
    void finish();

private:
    struct Status
    {
        QString problem;
    };

    JsonReader(const QJsonObject& object, const QString& path, const std::shared_ptr<Status>& status);

    QJsonValue take(const QString& key);
    QJsonValue takeOptional(const QString& key);
    QString pathOf(const QString& key) const;
    QList<JsonReader> readObjects(const QString& key, const QJsonArray& array);
    QStringList readStrings(const QString& key, const QJsonArray& array);

    QJsonObject m_object;
    QString m_path;
    QSet<QString> m_taken;
    std::shared_ptr<Status> m_status;
};
```

```cpp
#include <QJsonDocument>
#include <QJsonParseError>
#include <cmath>

namespace
{

/// 2^53: every integer up to this size is exact in a double.
constexpr double LargestExactInteger = 9007199254740992.0;

QString elementOf(const QString& key, int index)
{
    return QString("%1[%2]").arg(key).arg(index);
}

}  // namespace

JsonReader::JsonReader(const QJsonObject& object)
    : JsonReader(object, QString(), std::make_shared<Status>())
{
}

JsonReader::JsonReader(const QJsonObject& object, const QString& path, const std::shared_ptr<Status>& status)
    : m_object(object)
    , m_path(path)
    , m_status(status)
{
}

std::optional<QJsonObject> JsonReader::parseObject(const QByteArray& bytes)
{
    QJsonParseError error;
    QJsonDocument document = QJsonDocument::fromJson(bytes, &error);
    if (error.error != QJsonParseError::NoError || !document.isObject())
    {
        return std::nullopt;
    }
    return document.object();
}

bool JsonReader::isInteger(const QJsonValue& value)
{
    if (!value.isDouble())
    {
        return false;
    }
    double number = value.toDouble();
    return std::floor(number) == number
        && std::fabs(number) <= LargestExactInteger;
}

QString JsonReader::string(const QString& key)
{
    QJsonValue value = take(key);
    if (!value.isUndefined() && !value.isString())
    {
        fail(key, "is not a string");
    }
    return value.toString();
}

QString JsonReader::optionalString(const QString& key)
{
    QJsonValue value = takeOptional(key);
    if (value.isUndefined())
    {
        return QString();
    }
    if (!value.isString())
    {
        fail(key, "is not a string");
        return QString();
    }
    if (value.toString().isEmpty())
    {
        fail(key, "is written out empty");
    }
    return value.toString();
}

QByteArray JsonReader::bytes(const QString& key, int length)
{
    QJsonValue value = take(key);
    if (value.isUndefined())
    {
        return QByteArray();
    }
    std::optional<QByteArray> decoded;
    if (value.isString())
    {
        decoded = Base64Url::decode(value.toString(), length);
    }
    if (!decoded.has_value())
    {
        fail(key, QString("is not base64url of %1 bytes").arg(length));
        return QByteArray();
    }
    return *decoded;
}

QList<QByteArray> JsonReader::optionalBytesList(const QString& key, int length)
{
    QStringList texts = optionalStrings(key);
    QList<QByteArray> values;
    for (int i = 0; i < texts.size(); ++i)
    {
        std::optional<QByteArray> decoded = Base64Url::decode(texts[i], length);
        if (!decoded.has_value())
        {
            fail(elementOf(key, i), QString("is not base64url of %1 bytes").arg(length));
            return {};
        }
        values.append(*decoded);
    }
    return values;

    for (const QString& key : keys)

        if (!m_taken.contains(key))
        {
            fail(key, "is not expected");
            return;
        }
    }
}

    {
        fail(key, "missing");
    }
    return value;
}

    return m_object.value(key);
}

}
```

```cpp
    const QByteArray& signingSeed() const { return m_signingSeed; }

    const QByteArray& verifyKey() const { return m_verifyKey; }
    const QByteArray& fingerprint() const { return m_fingerprint; }

private:
```

```cpp
{

}
```

### `src/services/KeyFile.cpp`

```cpp
#include "KeyFile.h"
#include "Base64Url.h"
#include "Crypto.h"
#include "JsonReader.h"

#include <QDir>
#include <QFile>
#include <QFileInfo>
#include <QJsonDocument>
#include <QJsonObject>
#include <QSaveFile>

KeyFileResult KeyFile::loadOrCreate(const QString& path)
{
    if (!QFileInfo::exists(path))
    {
        return create(path);
    }
    return load(path);
}

KeyFileResult KeyFile::load(const QString& path)
{
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly))
    {
        return KeyFileResult{KeyFileStatus::Fault, std::nullopt, file.errorString()};
    }
    QByteArray bytes = file.readAll();
    if (file.error() != QFileDevice::NoError)
    {
        return KeyFileResult{KeyFileStatus::Fault, std::nullopt, file.errorString()};
    }

    std::optional<QJsonObject> object = JsonReader::parseObject(bytes);
    if (!object.has_value())
    {
        return KeyFileResult{KeyFileStatus::Unreadable, std::nullopt, "the key file is not a JSON object"};
    }
    JsonReader json(*object);
    if (json.integer("format") != Format)
    {
        json.fail("format", "is not a version this app reads");
    }
    QByteArray sealingSecret = json.bytes("sealingSecret", Crypto::KeyBytes);
    QByteArray signingSeed = json.bytes("signingSeed", Crypto::KeyBytes);
    json.finish();
    if (json.failed())
    {
        return KeyFileResult{KeyFileStatus::Unreadable, std::nullopt, json.problem()};
    }
    return KeyFileResult{KeyFileStatus::Loaded, Identity::fromSecrets(sealingSecret, signingSeed), QString()};
}

KeyFileResult KeyFile::create(const QString& path)
{
    Identity identity = Identity::generate();
    QJsonObject json;
    json["format"] = Format;
    json["sealingSecret"] = Base64Url::encode(identity.sealingSecret());
    json["signingSeed"] = Base64Url::encode(identity.signingSeed());
    QByteArray bytes = QJsonDocument(json).toJson(QJsonDocument::Compact);

    QDir().mkpath(QFileInfo(path).absolutePath());
    QSaveFile file(path);
    if (!file.open(QIODevice::WriteOnly)
        || file.write(bytes) != bytes.size()
        || !file.commit())
    {
        return KeyFileResult{KeyFileStatus::Fault, std::nullopt, file.errorString()};
    }
    QFile::setPermissions(path, QFileDevice::ReadOwner | QFileDevice::WriteOwner);
    return KeyFileResult{KeyFileStatus::Created, identity, QString()};
}
```

```cpp
#pragma once

#include "AccessList.h"
#include "Id.h"

#include <QByteArray>
#include <QList>
#include <QString>
#include <optional>

/// One recipient entry: a fingerprint, and the data key sealed to that recipient's X25519 key.
struct Recipient
{
    QByteArray fingerprint;
    QByteArray sealedKey;
};

struct HeaderRead;

/// The plaintext header line that opens every ward file and version. Its exact bytes, without
/// the newline that ends them, are the associated data of the payload's encryption, so a
/// header is never rebuilt from what was parsed.
class WardHeader
{
public:
    /// The format version this app writes, and the only one it reads.
    static constexpr int Format = 1;

    /// The header of a new write: document, a nonce drawn fresh from randombytes_buf, and
    /// dataKey sealed to each of recipients, in their order. Its line is built here, once.
    static WardHeader build(const DocumentId& document, const QByteArray& dataKey, const QList<RecipientKeys>& recipients);

    /// The header line holds. Its format key is read first: an integer above Format is Newer,
    /// and anything but Format is Unreadable; the rest is then read strictly.
    static HeaderRead parse(const QByteArray& line);

    const DocumentId& document() const { return m_document; }
    const QByteArray& nonce() const { return m_nonce; }
    const QList<Recipient>& recipients() const { return m_recipients; }
    const QByteArray& line() const { return m_line; }

    /// The data key sealed to the recipient with that fingerprint, or none when the header
    /// does not name it.
    std::optional<QByteArray> sealedKeyFor(const QByteArray& fingerprint) const;

private:
    WardHeader(const DocumentId& document, const QByteArray& nonce, const QList<Recipient>& recipients, const QByteArray& line);

    DocumentId m_document;
    QByteArray m_nonce;
    QList<Recipient> m_recipients;
    QByteArray m_line;
};

enum class HeaderStatus
{
    Read,
    Newer,      ///< the format is above every version this app reads
    Unreadable  ///< fails validation; problem says where
};

struct HeaderRead
{
    HeaderStatus status;
    QString problem;
    std::optional<WardHeader> header;  ///< when Read
};
```

```cpp
WardHeader::WardHeader(const DocumentId& document, const QByteArray& nonce, const QList<Recipient>& recipients, const QByteArray& line)
    : m_document(document)
    , m_nonce(nonce)
    , m_recipients(recipients)
    , m_line(line)
{
}

WardHeader WardHeader::build(const DocumentId& document, const QByteArray& dataKey, const QList<RecipientKeys>& recipients)
{
    QByteArray nonce = Crypto::randomBytes(Crypto::NonceBytes);
    QList<Recipient> entries;
    QJsonArray recipientsJson;
    for (const RecipientKeys& keys : recipients)
    {
        Recipient entry{Identity::fingerprintOf(keys.publicKey, keys.verifyKey), Crypto::seal(dataKey, keys.publicKey)};
        QJsonObject entryJson;
        entryJson["fingerprint"] = Base64Url::encode(entry.fingerprint);
        entryJson["sealedKey"] = Base64Url::encode(entry.sealedKey);
        recipientsJson.append(entryJson);
        entries.append(entry);
    }

    QJsonObject json;
    json["format"] = Format;
    json["document"] = document.toString();
    json["nonce"] = Base64Url::encode(nonce);
    json["recipients"] = recipientsJson;
    QByteArray line = QJsonDocument(json).toJson(QJsonDocument::Compact);
    Q_ASSERT(!line.contains('\n'));
    return WardHeader(document, nonce, entries, line);
}

HeaderRead WardHeader::parse(const QByteArray& line)
{
    std::optional<QJsonObject> object = JsonReader::parseObject(line);
    if (!object.has_value())
    {
        return HeaderRead{HeaderStatus::Unreadable, "the header is not a JSON object", std::nullopt};
    }
    QJsonValue format = object->value("format");
    if (!JsonReader::isInteger(format))
    {
        return HeaderRead{HeaderStatus::Unreadable, "format: is not an integer", std::nullopt};
    }
    if (format.toDouble() > Format)
    {
        return HeaderRead{HeaderStatus::Newer, QString(), std::nullopt};
    }
    if (format.toDouble() != Format)
    {
        return HeaderRead{HeaderStatus::Unreadable, "format: is not a version this app reads", std::nullopt};
    }

    JsonReader json(*object);
    json.integer("format");
    DocumentId document = DocumentId::fromString(Base64Url::encode(json.bytes("document", Crypto::IdBytes)));
    QByteArray nonce = json.bytes("nonce", Crypto::NonceBytes);
    QList<Recipient> recipients;
    const QList<JsonReader> entryReaders = json.objects("recipients");
    for (JsonReader entry : entryReaders)
    {
        QByteArray fingerprint = entry.bytes("fingerprint", Crypto::FingerprintBytes);
        QByteArray sealedKey = entry.bytes("sealedKey", Crypto::SealedKeyBytes);
        entry.finish();
        recipients.append(Recipient{fingerprint, sealedKey});
    }
    json.finish();
    if (json.failed())
    {
        return HeaderRead{HeaderStatus::Unreadable, json.problem(), std::nullopt};
    }
    return HeaderRead{HeaderStatus::Read, QString(), WardHeader(document, nonce, recipients, line)};
}

std::optional<QByteArray> WardHeader::sealedKeyFor(const QByteArray& fingerprint) const
{
    for (const Recipient& recipient : m_recipients)
    {
        if (recipient.fingerprint == fingerprint)
        {
            return recipient.sealedKey;
        }
    }
    return std::nullopt;
}
```

```cpp
#include "WardFile.h"
#include "Crypto.h"
#include "JsonReader.h"

#include <QJsonDocument>
#include <QSet>

namespace
{

WardRead unreadable(const QString& problem, const std::optional<WardHeader>& header)
{
    return WardRead{WardReadStatus::Unreadable, problem, header, QByteArray(), std::nullopt};
}

/// Every recipient entry is computed from exactly one device's or invite's pair of public keys
/// in access, and each of those has exactly one entry.
bool headerMatches(const WardHeader& header, const AccessList& access)
{
    QList<QByteArray> expected;
    const QList<RecipientKeys> recipients = access.recipients();
    for (const RecipientKeys& keys : recipients)
    {
        expected.append(Identity::fingerprintOf(keys.publicKey, keys.verifyKey));
    }
    QList<QByteArray> named;
    for (const Recipient& recipient : header.recipients())
    {
        named.append(recipient.fingerprint);
    }
    QSet<QByteArray> expectedSet(expected.begin(), expected.end());
    QSet<QByteArray> namedSet(named.begin(), named.end());
    return expectedSet.size() == expected.size()
        && namedSet.size() == named.size()
        && expectedSet == namedSet;
}

}  // namespace

QByteArray WardFile::write(const DocumentId& document, const QByteArray& dataKey, const WardPayload& payload)
{
    WardHeader header = WardHeader::build(document, dataKey, payload.ward.access().recipients());
    QByteArray json = QJsonDocument(payload.toJson()).toJson(QJsonDocument::Compact);
    return header.line() + '\n' + Crypto::encrypt(qCompress(json), header.line(), header.nonce(), dataKey);
}

WardRead WardFile::read(const QByteArray& bytes, const Identity& reader, PayloadKind kind)
{
    qsizetype boundary = bytes.indexOf('\n');
    if (boundary < 0)
    {
        return unreadable("the file has no header line", std::nullopt);
    }
    QByteArray line = bytes.left(boundary);
    HeaderRead headerRead = WardHeader::parse(line);
    if (headerRead.status == HeaderStatus::Newer)
    {
        return WardRead{WardReadStatus::Newer, QString(), std::nullopt, QByteArray(), std::nullopt};
    }
    if (headerRead.status == HeaderStatus::Unreadable)
    {
        return unreadable(headerRead.problem, std::nullopt);
    }
    const WardHeader& header = *headerRead.header;

    if (header.recipients().isEmpty())
    {
        return WardRead{WardReadStatus::Deleted, QString(), header, QByteArray(), std::nullopt};
    }
    std::optional<QByteArray> sealedKey = header.sealedKeyFor(reader.fingerprint());
    if (!sealedKey.has_value())
    {
        return WardRead{WardReadStatus::NotNamed, QString(), header, QByteArray(), std::nullopt};
    }

    std::optional<QByteArray> dataKey = reader.unseal(*sealedKey);
    if (!dataKey.has_value())
    {
        return unreadable("the data key does not unseal", header);
    }
    std::optional<QByteArray> compressed = Crypto::decrypt(bytes.mid(boundary + 1), line, header.nonce(), *dataKey);
    if (!compressed.has_value())
    {
        return unreadable("the payload does not decrypt", header);
    }
    std::optional<QJsonObject> object = JsonReader::parseObject(qUncompress(*compressed));
    if (!object.has_value())
    {
        return unreadable("the payload is not a compressed JSON object", header);
    }

    JsonReader json(*object);
    WardPayload payload = WardPayload::fromJson(json, kind);
    if (json.failed())
    {
        return unreadable(json.problem(), header);
    }
    if (!headerMatches(header, payload.ward.access()))
    {
        return unreadable("the header and the access list differ", header);
    }
    return WardRead{WardReadStatus::Read, QString(), header, *dataKey, payload};
}
```

```cpp
StoreRead FileWardStore::read(const DocumentId& document) const
{
    QFile file(pathOf(document));
    if (!file.exists())
    {
        return StoreRead{StoreReadStatus::Missing, QByteArray(), QString()};
    }
    if (!file.open(QIODevice::ReadOnly))
    {
        return StoreRead{StoreReadStatus::Fault, QByteArray(), file.errorString()};
    }
    QByteArray bytes = file.readAll();
```

```cpp
LocalRead WardSession::readLocal(const WardStore& store, const Identity& identity, const DocumentId& document)
{
    StoreRead stored = store.read(document);
    if (stored.status == StoreReadStatus::Missing)
    {
        return notOpened(OpenStatus::Missing, "this device holds no file for the ward");
    }
    if (stored.status == StoreReadStatus::Fault)
    {
        return notOpened(OpenStatus::Fault, stored.problem);
    }

    WardRead read = WardFile::read(stored.bytes, identity, PayloadKind::LocalFile);
    switch (read.status)
    {
    case WardReadStatus::Read:
        break;
    case WardReadStatus::Newer:
        return notOpened(OpenStatus::Newer, "a newer Ward Planning wrote the file");
    case WardReadStatus::Unreadable:
        return notOpened(OpenStatus::CannotRead, read.problem);
    case WardReadStatus::Deleted:
        return notOpened(OpenStatus::CannotRead, "the header names no one");
    case WardReadStatus::NotNamed:
        return notOpened(OpenStatus::CannotRead, "the header does not name this device");
    }
    if (read.header->document() != document)
    {
        return notOpened(OpenStatus::CannotRead, "the file holds another ward");
    }
    return LocalRead{OpenResult{OpenStatus::Opened, QString()}, read.payload, read.dataKey};
}

bool WardSession::retryPendingSave()
{
    if (m_savePending)
    {
        save();
    }
    return !m_savePending;
}

void WardSession::save()
{
    QByteArray bytes = WardFile::write(m_documentId, m_dataKey, WardPayload{m_document, m_landed, m_device});
    QString problem;
    if (m_store->write(m_documentId, bytes, &problem))
    {
        m_savePending = false;
        return;
    }
    if (!m_savePending)
    {
        m_savePending = true;
        emit saveFailed(problem);
    }
}
```

```cpp
namespace
{

QJsonValue editedValue(const QJsonValue& json, const QStringList& path, const QJsonValue& value)
{
    if (path.isEmpty())
    {
        return value;
    }
    QString step = path.first();
    QStringList rest = path.mid(1);
    if (json.isArray())
    {
        QJsonArray array = json.toArray();
        int index = step.toInt();
        array[index] = editedValue(array[index], rest, value);
        return array;
    }
    QJsonObject object = json.toObject();
    QJsonValue replaced = editedValue(object.value(step), rest, value);
    if (replaced.isUndefined())
    {
        object.remove(step);
    }
    else
    {
        object[step] = replaced;
    }
    return object;
}

}  // namespace
```

**The reader rule.** Every `fromJson(const QJsonObject& json)` becomes
`static T fromJson(JsonReader json)` and reads exactly what its `toJson` writes:
- every key its `toJson` always writes, through the call for its type; every key its `toJson`
  leaves out when empty, through the matching `optional...` call; then `json.finish()`;
- a value written as one of a fixed set of words (gender, ministering organisation, response
  area, tag level, contact method and outcome, task state) fails for any other word through
  `json.fail(key, "is not one of ...")`, naming the words;
- a date or time fails when it does not parse back with the format `toJson` writes it in;
- every lenient fallback in today's readers (`if (date.isValid())`, `toString()` of a missing
  key, a default for an unknown enum word) goes;
- a type that reads its own JSON value (`Gender::fromJson(const QJsonValue&)`) takes
  `json.value(key)` and reports through `json.fail`.

`DocumentMetadata::readFromJson(JsonReader& json)` takes the document's own reader by
reference, since its keys live in the document's object.

**One value always writes the same JSON.** Every hash a `toJson` writes as an array is written
in id order, and every set of ids or strings in sorted order; `Document`'s
`serializeHashToJson` sorts by `id().toString()`. No reader depends on the order.

**`docs/FORMAT.md`** (new):

```markdown
# The .wardplanning Format

The specification of a Ward Planning ward file and of the device key file, format version 1.
A reader built from this document and `docs/SHARED_WARD_DESIGN.md` alone reads every file the
app writes; `tests/spec` is such a reader, and the test suite checks it against the app.

## Conventions

- **Binary values** are base64url without padding (RFC 4648 section 5, no `=`). Each has a fixed
  length: a document id or user id 16 bytes (22 characters), a nonce 24 (32), a fingerprint 16
  (22), a key, seed or former-key hash 32 (43), a sealed key 80 (107). A value of another length,
  with padding, with characters outside the base64url alphabet, or with non-zero unused trailing
  bits is malformed.
- **JSON** is UTF-8. An integer is a JSON number with no fractional part.
- **Every field is required**, except one marked *omitted when empty*: its writer leaves it out
  when it is empty (an empty string or array, `false`, or no value), and a reader reads its
  absence as empty. Such a field written out empty is malformed.
- **Nothing else is accepted.** A reader refuses a file with a field missing, malformed, of the
  wrong type, or not listed here, and reads nothing from it.
- **Collections** are written in id order and sets in sorted order. A reader does not depend on
  either order.

## Format versions

The header's `format` integer covers the whole file: the header, the sealing and the payload.
It is read first, and it is the one thing no format version changes: a file opens with a
one-line JSON header whose `format` key is an integer. A reader treats a `format` above every
version it knows as a newer format, reads a version it knows with that version's reader, and
treats anything else as unreadable. A release that changes any field raises the version.

## The key file

`keys/device.key` in app data (`QStandardPaths::AppLocalDataLocation`), one compact JSON object:

| Key | Type | Holds |
|---|---|---|
| `format` | integer | 1 |
| `sealingSecret` | 32 bytes | the device's X25519 secret key |
| `signingSeed` | 32 bytes | the device's Ed25519 seed |

The X25519 public key is `crypto_scalarmult_base(sealingSecret)`. The Ed25519 verify key is the
public key `crypto_sign_seed_keypair(signingSeed)` gives.

## Fingerprint

16-byte unkeyed BLAKE2b, with a zero salt and the personalisation `wp-fingerprint` zero-padded
to 16 bytes, over the X25519 public key followed by the Ed25519 verify key (64 bytes in).

## Framing

A file is the header line's bytes, one `\n` (0x0A), then the payload's bytes. The header is
compact JSON, which escapes every newline inside it, so the first `\n` is the boundary.

## Header

| Key | Type | Holds |
|---|---|---|
| `format` | integer | 1 |
| `document` | 16 bytes | the document id |
| `nonce` | 24 bytes | the payload's nonce, drawn from `randombytes_buf` on every write |
| `recipients` | array of objects | one per device and one per open invite |

Each recipient:

| Key | Type | Holds |
|---|---|---|
| `fingerprint` | 16 bytes | the recipient's fingerprint |
| `sealedKey` | 80 bytes | the 32-byte data key sealed with `crypto_box_seal` to the recipient's X25519 public key |

## Payload encryption

The payload's bytes are XChaCha20-Poly1305 (`crypto_aead_xchacha20poly1305_ietf`) under the
data key and the header's nonce, with the header line's exact bytes, without the `\n`, as the
associated data; the 16-byte tag follows the ciphertext. Decrypted, they are the compact payload
JSON compressed with Qt's `qCompress`: a 4-byte big-endian length of the uncompressed bytes,
then a zlib stream.

## Payload

One object. Its parts:

| Key | Type | Holds |
|---|---|---|
| `ward` | object | the ward's content (see *ward*) |
| `access` | object | who may read the ward (see *access*) |
| `landed` | object | each device's landed mark (see *landed*) |
| `device` | object | this device's own state (see *device*): required in a local file, and refused in a version on the server |

### access

| Key | Type | Holds |
|---|---|---|
| `users` | array of user objects | every user |
| `invites` | array of invite objects | the open invites; omitted when empty |
| `formerKeys` | array of 32-byte values | BLAKE2b-256, personalised `wp-former-key`, of each data key the ward used before its current one, oldest first; omitted when empty |

A user:

| Key | Type | Holds |
|---|---|---|
| `id` | 16 bytes | the user's id within this ward |
| `name` | string | the name they gave |
| `role` | `"admin"` or `"member"` | their role |
| `devices` | array of device objects | their devices |

A device:

| Key | Type | Holds |
|---|---|---|
| `name` | string | the device's name |
| `publicKey` | 32 bytes | its X25519 public key |
| `verifyKey` | 32 bytes | its Ed25519 verify key |

An invite:

| Key | Type | Holds |
|---|---|---|
| `for` | `"device"` or `"user"` | what it joins as |
| `maker` | 16 bytes | the id of the user who made it |
| `role` | `"admin"` or `"member"` | the role its joiner takes; user invites only, and refused on a device invite |
| `label` | string | who it is for; user invites only, and refused on a device invite |
| `publicKey` | 32 bytes | the invite's X25519 public key |
| `verifyKey` | 32 bytes | the invite's Ed25519 verify key |

### landed

An object whose keys are device fingerprints (16 bytes, base64url) and whose values are
integers: the highest journal sequence number of that device the version includes.

### device

| Key | Type | Holds |
|---|---|---|
| `journal` | journal object | this device's commands not yet seen to land |
| `toRedo` | array of to-redo groups | abandoned journals' descriptions; omitted when empty |
| `baseVersion` | integer | the server version this device holds; omitted until it has one |
| `dismissedAccess` | access object | the access list as of the last dismissed access notice; omitted until one is dismissed |
| `singleHolderNoticeDismissed` | `true` | omitted when false |
| `singleAdminNoticeDismissed` | `true` | omitted when false |
| `failed` | array of strings | addresses and unit numbers that did not resolve; omitted when empty |
| `noLongerShared` | `true` | the ward is no longer this device's; omitted when false |
| `inviteSeeds` | array of 32-byte values | the seed of each open invite this device made; omitted when empty |

A journal:

| Key | Type | Holds |
|---|---|---|
| `lastSequence` | integer | the last sequence number given to an entry |
| `entries` | array of entry objects | in the order they were made; omitted when empty |

An entry: `sequence` (integer) and `command` (a command object). A command object:

| Key | Type | Holds |
|---|---|---|
| `type` | string | the command type, one of those under *Commands* |
| `description` | description object | what the user did |
| `fields` | object | the type's own fields (see *Commands*) |

A description: `heading` (string) and `lines` (array of strings; omitted when empty).

A to-redo group:

| Key | Type | Holds |
|---|---|---|
| `descriptions` | array of description objects | the abandoned journal's descriptions, in order |
| `clashed` | integer | the index of the one that stopped the replay |
| `stop` | `"conflicted"` or `"refused"` | what stopped it |
| `refusal` | string | the rule's wording; with `"refused"` only |

### ward

<one table per model, written from its toJson: key, type and encoding, required or omitted
when empty, and for a word-valued field the words>

### Commands

<one table per registered command type, by its type name, written from its toJson, with the
change shapes (`{before, after}`, `{added, removed}`) given once>

## Header and access list agree

Every recipient's fingerprint is computed from exactly one device's or invite's pair of public
keys in `access`, and every device and open invite there has exactly one recipient. A file that
fails this is refused.

## A deleted ward's final version

A header with an empty `recipients` array and a fresh nonce, followed by its `\n` and nothing
after it. A reader recognises it by the empty `recipients`, before any payload rule applies. No
local file takes this form.
```

```cpp
    [[noreturn]] void refuse(const std::string& key, const std::string& what) const;
    void done() const;

private:
    const nlohmann::json& take(const std::string& key);
    const nlohmann::json* takeOptional(const std::string& key);
    std::string pathOf(const std::string& key) const;

    nlohmann::json m_object;
    std::string m_path;
    std::set<std::string> m_taken;
};

/// Base64url without padding, through sodium_base642bin and sodium_bin2base64 with
/// sodium_base64_VARIANT_URLSAFE_NO_PADDING; decode refuses any text that does not re-encode
/// to itself.
std::string encode(const std::vector<unsigned char>& bytes);
std::optional<std::vector<unsigned char>> decode(const std::string& text, std::size_t length);
```

`Fields.cpp` implements each call as the convention in `docs/FORMAT.md` states it (an integer is
`is_number_integer()`, an optional field present and empty is refused). `Envelope.h/.cpp` holds
`readKeyFile`, `fingerprintOf`, `splitAtHeader`, `readHeader`, `unsealDataKey`, `decrypt` and
`inflate` (the 4-byte big-endian length, then `uncompress`). `Payload.h/.cpp` holds one function
per table in `docs/FORMAT.md`, each taking a `Fields` and returning the `nlohmann::json` it
re-writes from the typed values it read (bytes re-encoded, optional fields left out when
absent), then calling `done()`: `readPayload`, `readAccess`, `readUser`, `readDevice`,
`readInvite`, `readLanded`, `readDeviceState`, `readJournal`, `readEntry`, `readCommand`,
`readDescription`, `readRedoGroup`, and one `read<Model>` per ward table and one
`read<Command>Fields` per command table, dispatched by `type`. `main.cpp` checks that the header's
fingerprints and the access list's keys agree exactly, as *Header and access list agree* states.

**Tests** (`SpecReaderTest`, which runs the reader with `QProcess` from
`WARD_PLANNING_SPEC_READER`):

**`InstanceLock`:**

```cpp
#pragma once

#include <QLockFile>
#include <QString>

/// The per-user lock that keeps one Ward Planning running, so two processes never write the
/// same ward file and journal. Only a dead holder makes it stale, never its age.
class InstanceLock
{
public:
    explicit InstanceLock(const QString& path);

    /// Takes the lock, unless a live process holds it.
    bool take();

private:
    QLockFile m_lock;
};
```

```cpp
#include "InstanceLock.h"

InstanceLock::InstanceLock(const QString& path)
    : m_lock(path)
{
    m_lock.setStaleLockTime(0);
}

bool InstanceLock::take()
{
    return m_lock.tryLock(0);
}
```

Recalled, and checked by `lockIsTakenOnceTheHolderIsKilled`: with a stale-lock time of 0, a
`QLockFile` is stale only when the process that wrote it is no longer running.

`AppData` gains `QString lockFilePath() const { return m_root + "/instance.lock"; }`.
`main.cpp`, directly after the application name and version are set and before the key file is
read: `QDir().mkpath(appData.root())`, `InstanceLock lock(appData.lockFilePath());`, and
`return 0;` when `lock.take()` answers `false`, so a second launch exits silently; plan 3's
hand-off brings the running window forward. Taking the lock before the key file means two first
starts cannot both make keys.

**`tests/lock`** is the executable `WardPlanningLockTests`, linked against `WardPlanningLib` and
`Qt6::Test`. Run with `hold <path>`, it takes the lock through `InstanceLock`, prints `held` or
`refused` and a newline, and when held waits until its standard input closes; run with
`take <path>`, it prints the same and exits 0 when held and 1 when refused; run with no arguments,
it runs `LockTest`, which starts copies of itself through `QCoreApplication::applicationFilePath()`.

**Tests** (`LockTest`):
- `secondProcessIsRefusedWhileTheFirstHoldsTheLock`: a `hold` copy prints `held`; a `take` copy
  of the same path prints `refused` and exits 1.
- `lockIsTakenOnceTheHolderIsKilled`: a `hold` copy prints `held` and a `take` copy is refused;
  the holder is killed with `QProcess::kill()` and its lock file is still on disk; a new `take`
  copy prints `held` and exits 0.

## Open questions for the user

The design is silent on these; each states the choice this plan makes.

1. **`docs/FORMAT.md` is written in task 2**, with the strict readers, rather than in a closing
   docs pass, since the design asks that it change in the same commit as any `toJson` it
   describes. It covers task 1's parts too.
2. **The key file** is `keys/device.key`, one JSON line holding `format`, `sealingSecret` and
   `signingSeed`; the public halves are derived on load, so the file cannot hold a mismatched pair.
3. **A key file that exists but cannot be read or parsed** stops the app with a message naming
   it, and the file is left as it is.
4. **The device name** is asked at first start (prefilled with the machine's host name), kept as
   `deviceName` in the settings file `MainWindow` already keeps, and cancelling quits.
5. **Messages for a local file that does not open**, new interface text: Missing *This ward is no
   longer on this device.*; CannotRead *This ward's file on this device could not be opened.*;
   Newer *This ward was saved by a newer version of Ward Planning. Update to open it.*; Fault
   *This ward's file could not be read just now. Try again.* Plan 3 replaces CannotRead's message
   with the download.
6. **A read fault is retried when the user opens the ward again**, with no retry timer.
7. **A file renamed to another ward's id** is refused (*the file holds another ward*), beside the
   associated-data check that refuses a changed header id.
8. **Switching ward while a save is pending** asks the closing question first.
9. **`TestClient` is defined here** (a device name, identity, store, fakes, session, `createWard`,
   `reopen`); plan 3 adds its server to the same class.
10. **`invites` and `formerKeys` are omitted when empty, and `landed` is always written**, as
    `docs/FORMAT.md` states.
