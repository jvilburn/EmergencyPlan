# Sharing Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-with-review to implement this plan task-by-task.

**Goal:** A ward is shared through the Ward Planning server: every command is pushed as the next
version as soon as it is saved, incoming versions are taken through the download checks in their
order, landed marks settle every unknown outcome, a push that drops a recipient rotates the data
key, and the access list, invites, Leave, presence and notices are built on that one path.

**Architecture:** `Server` is one abstract class with the calls the app makes. `HttpServer`
implements it over a `Transport` that carries method, path, headers and body out and status,
headers and body back; the app's transport is HTTP and the tests' is `FakeServer`, in process, so
every client test runs the real wire encoding. `WardSession` owns the sync orchestration: one call
in flight, look before any retry, take a version (checks, trim by landed mark, raise the counter,
replay, save, push), push (rotation, former keys, landed marks), and the no-longer-shared state.
Access-list changes are commands like any other, with their rules in `AccessRules`.

**Tech Stack:** Qt 6.11 (Core, Gui, Widgets, Network, Test, and WebSockets once the channel's wire
is settled), C++17, MSVC 2022, CMake + Ninja via `build.bat`, libsodium through plan 2, Qt Test.

**Design authority:** `docs/SHARED_WARD_DESIGN.md`. Section names in *italics* are its sections.
This plan builds on `docs/plans/2026-10-17-commands-and-replay.md` (plan 1) and on plan 2 (the ward
file), whose assumed interfaces are listed below.

### How the session answers the server

**A write is stored or it is not**, and the client branches on nothing finer. `HttpServer`
decodes a write's answer to stored or not stored, and a read's to the ward, missing, a fault, or
unreached; the server's own error codes are for its logs.

| Call | Answer | What the session does |
|---|---|---|
| POST, PUT | stored | the push landed: base, key, recipients, marks, journal trimmed, save, push again if anything waits |
| POST, PUT | not stored (any error, or no answer) | look |
| look | the ward, newer than the base | the download checks, then take: trim by the mark, replay, save, push |
| look | the ward, unchanged since a refused write | `Faulted`, told once; the journal stays, and the next retry looks and pushes again |
| look | a header without this device, or naming no one | no longer shared |
| look | missing | a ward this device has had from or given to the server, or a first download, is no longer shared; one never on the server makes its first push, unless that push was just refused, which is a fault |
| look | a fault | `Faulted` |
| look | unreached | `Offline` |

A look is a fetch: it shows the head and carries the landed mark that settles a write whose
answer was lost, so nothing is pushed twice. A failed check on the ward is the state the check
names.

### `src/server/Transport.h`

```cpp
#pragma once

#include <QByteArray>
#include <QHash>
#include <QObject>
#include <optional>

/// The names of the Ward- headers, in lower case.
namespace WireHeader
{
constexpr const char* BaseVersion = "ward-base-version";
constexpr const char* Signer = "ward-signer";
constexpr const char* Signature = "ward-signature";
constexpr const char* Version = "ward-version";
constexpr const char* Publisher = "ward-publisher";
constexpr const char* Published = "ward-published";
}

/// A request as it goes on the wire. Header names are in lower case.
struct WireRequest
{
    QByteArray method;
    QByteArray path;
    QHash<QByteArray, QByteArray> headers;
    QByteArray body;
};

/// An answer as it comes off the wire. Header names are in lower case.
struct WireResponse
{
    std::optional<int> status;  ///< none when no answer arrived
    QHash<QByteArray, QByteArray> headers;
    QByteArray body;
};

/// One request in flight. It finishes once.
class TransportCall : public QObject
{
    Q_OBJECT

public:
    explicit TransportCall(QObject* parent) : QObject(parent) {}

signals:
    void finished(const WireResponse& response);
};

/// Carries requests to the server and its answers back.
class Transport
{
public:
    virtual ~Transport() = default;

    /// Sends request. The caller owns the call and deletes it once it has finished.
    virtual TransportCall* send(const WireRequest& request) = 0;
};
```

### `src/server/Server.h`

```cpp
#pragma once

#include "DeviceIdentity.h"
#include "DocumentId.h"
#include "Fingerprint.h"

#include <QByteArray>
#include <QDateTime>
#include <QObject>
#include <optional>

/// What a call's answer means to the client. A write is stored or it is not; a read returns
/// the ward, finds none, or fails. The server's own error codes are for its logs.
enum class ServerOutcome
{
    Stored,     ///< a write the server stored: a success status carrying its version
    NotStored,  ///< a write answered with anything else, or not answered
    Ward,       ///< a read answered with the ward and its version
    Missing,    ///< a read answered 404: the server has no such ward
    Fault,      ///< a read answered with anything else
    Unreached   ///< a read that got no answer
};

struct ServerAnswer
{
    ServerOutcome outcome;
    std::optional<qint64> version;         ///< ward-version; always set for Stored and Ward
    std::optional<Fingerprint> publisher;  ///< ward-publisher
    QDateTime published;                   ///< ward-published; invalid when absent
    QByteArray body;                       ///< a head's header line, or a version's body
};

/// One call to the server. It answers once.
class ServerCall : public QObject
{
    Q_OBJECT

public:
    explicit ServerCall(QObject* parent) : QObject(parent) {}

signals:
    void answered(const ServerAnswer& answer);
};

/// The calls the app makes to the Ward Planning server. The caller owns each call it gets
/// and deletes it once it has answered.
class Server
{
public:
    virtual ~Server() = default;

    /// POST /documents: version 1 of a new document, signed by a device its header names.
    virtual ServerCall* create(const DocumentId& id, const QByteArray& body, const DeviceIdentity& signer) = 0;

    /// GET /documents/{id}/head: the current version's number, publisher, time and header line.
    virtual ServerCall* head(const DocumentId& id) = 0;

    /// GET /documents/{id}: the current version's number and body.
    virtual ServerCall* fetch(const DocumentId& id) = 0;

    /// PUT /documents/{id}: the next version, conditional on baseVersion being current.
    virtual ServerCall* push(const DocumentId& id, qint64 baseVersion, const QByteArray& body, const DeviceIdentity& signer) = 0;
};
```

### `src/server/SignedLine.cpp`

```cpp
#include "SignedLine.h"
#include "Base64Url.h"
#include "Crypto.h"

namespace
{

/// The hashes are BLAKE2b-256 of the exact bytes on either side of the body's first newline.
QByteArray line(const QByteArray& call, const DocumentId& id, const QByteArray& base, const QByteArray& body)
{
    int boundary = body.indexOf('\n');
    Q_ASSERT_X(boundary >= 0, "SignedLine", "a version body holds its header line");
    QByteArray headerHash = Base64Url::encode(Crypto::blake2b256(body.left(boundary))).toLatin1();
    QByteArray payloadHash = Base64Url::encode(Crypto::blake2b256(body.mid(boundary + 1))).toLatin1();
    return "wardplanning-v1 " + call
        + " " + id.toString().toLatin1()
        + " " + base
        + " " + headerHash
        + " " + payloadHash;
}

}  // namespace

QByteArray SignedLine::create(const DocumentId& id, const QByteArray& body)
{
    return line("create", id, "0", body);
}

QByteArray SignedLine::push(const DocumentId& id, qint64 baseVersion, const QByteArray& body)
{
    return line("push", id, QByteArray::number(baseVersion), body);
}

QByteArray SignedLine::channel(const DocumentId& id)
{
    return "wardplanning-v1 channel " + id.toString().toLatin1() + " - - -";
}
```

### `src/server/HttpServer.h`

```cpp
#pragma once

#include "Server.h"
#include "Transport.h"

/// A write is answered stored or not stored; a read with the ward, missing, or a fault.
enum class CallKind
{
    Write,
    Read
};

/// The server's calls encoded on the wire, over any transport: the app's is HTTP, and the
/// tests' is FakeServer, so every client test runs this encoding.
class HttpServer : public Server
{
public:
    explicit HttpServer(Transport* transport);

    ServerCall* create(const DocumentId& id, const QByteArray& body, const DeviceIdentity& signer) override;
    ServerCall* head(const DocumentId& id) override;
    ServerCall* fetch(const DocumentId& id) override;
    ServerCall* push(const DocumentId& id, qint64 baseVersion, const QByteArray& body, const DeviceIdentity& signer) override;

private:
    ServerCall* send(CallKind kind, const WireRequest& request);

    Transport* m_transport;
};

/// A server call carried by one transport call, decoding its answer by the kind of call it is.
class HttpServerCall : public ServerCall
{
    Q_OBJECT

public:
    HttpServerCall(CallKind kind, TransportCall* call, QObject* parent);

private slots:
    void onFinished(const WireResponse& response);

private:
    CallKind m_kind;
};
```

### `src/server/HttpServer.cpp`

```cpp
#include "HttpServer.h"
#include "Base64Url.h"
#include "SignedLine.h"

namespace
{

QByteArray documentPath(const DocumentId& id)
{
    return "/documents/" + id.toString().toLatin1();
}

QHash<QByteArray, QByteArray> signedHeaders(const QByteArray& line, const DeviceIdentity& signer)
{
    QHash<QByteArray, QByteArray> headers;
    QString keys = Base64Url::encode(signer.publicKey()) + "." + Base64Url::encode(signer.verifyKey());
    headers.insert(WireHeader::Signer, keys.toLatin1());
    headers.insert(WireHeader::Signature, Base64Url::encode(signer.sign(line)).toLatin1());
    return headers;
}

/// A version number as the server writes it: a plain decimal, at least 1.
std::optional<qint64> versionNumber(const QByteArray& text)
{
    bool ok = false;
    qint64 value = text.toLongLong(&ok);
    if (!ok || value < 1 || QByteArray::number(value) != text)
    {
        return std::nullopt;
    }
    return value;
}

bool isSuccess(int status)
{
    return status >= 200 && status < 300;
}

/// A write is stored only when a success status carries the version it was stored as.
ServerOutcome writeOutcome(const WireResponse& response, const std::optional<qint64>& version)
{
    if (response.status.has_value() && isSuccess(*response.status) && version.has_value())
    {
        return ServerOutcome::Stored;
    }
    return ServerOutcome::NotStored;
}

ServerOutcome readOutcome(const WireResponse& response, const std::optional<qint64>& version)
{
    if (!response.status.has_value())
    {
        return ServerOutcome::Unreached;
    }
    if (isSuccess(*response.status) && version.has_value())
    {
        return ServerOutcome::Ward;
    }
    if (*response.status == 404)
    {
        return ServerOutcome::Missing;
    }
    return ServerOutcome::Fault;
}

}  // namespace

HttpServer::HttpServer(Transport* transport)
    : m_transport(transport)
{
}

ServerCall* HttpServer::create(const DocumentId& id, const QByteArray& body, const DeviceIdentity& signer)
{
    WireRequest request;
    request.method = "POST";
    request.path = "/documents";
    request.headers = signedHeaders(SignedLine::create(id, body), signer);
    request.body = body;
    return send(CallKind::Write, request);
}

ServerCall* HttpServer::head(const DocumentId& id)
{
    WireRequest request;
    request.method = "GET";
    request.path = documentPath(id) + "/head";
    return send(CallKind::Read, request);
}

ServerCall* HttpServer::fetch(const DocumentId& id)
{
    WireRequest request;
    request.method = "GET";
    request.path = documentPath(id);
    return send(CallKind::Read, request);
}

ServerCall* HttpServer::push(const DocumentId& id, qint64 baseVersion, const QByteArray& body, const DeviceIdentity& signer)
{
    WireRequest request;
    request.method = "PUT";
    request.path = documentPath(id);
    request.headers = signedHeaders(SignedLine::push(id, baseVersion, body), signer);
    request.headers.insert(WireHeader::BaseVersion, QByteArray::number(baseVersion));
    request.body = body;
    return send(CallKind::Write, request);
}

ServerCall* HttpServer::send(CallKind kind, const WireRequest& request)
{
    return new HttpServerCall(kind, m_transport->send(request), nullptr);
}

HttpServerCall::HttpServerCall(CallKind kind, TransportCall* call, QObject* parent)
    : ServerCall(parent)
    , m_kind(kind)
{
    call->setParent(this);
    connect(call, &TransportCall::finished, this, &HttpServerCall::onFinished);
}

void HttpServerCall::onFinished(const WireResponse& response)
{
    std::optional<qint64> version = versionNumber(response.headers.value(WireHeader::Version));
    ServerOutcome outcome = m_kind == CallKind::Write
        ? writeOutcome(response, version)
        : readOutcome(response, version);
    ServerAnswer answer{outcome,
                        version,
                        Fingerprint::fromString(QString::fromLatin1(response.headers.value(WireHeader::Publisher))),
                        QDateTime::fromString(QString::fromLatin1(response.headers.value(WireHeader::Published)), Qt::ISODate),
                        response.body};
    emit answered(answer);
}
```

A success status without a version it can read is not stored, or a fault for a read, so the

`ward-publisher` and `ward-published` without requiring them; the conformance suite (task 12)
asserts the server sends every header the design's table lists.

```cpp
/// What the download checks found, by the first check that stopped them.
enum class VersionVerdict
{
    Accepted,       ///< passed every check asked of it
    NewerFormat,    ///< check 1: written by a newer app
    RolledBack,     ///< check 2: below the base this device holds
    Deleted,        ///< check 3: the header names no recipient
    NotNamed,       ///< check 3: the header names others, but not this reader
    Unreadable,     ///< checks 1, 4, 5 and 6: an unreadable header, a key that does not unseal,
                    ///< a payload that does not read, or a header that does not match the access list
    NotDescending   ///< check 7: under a key this device never held for the ward, naming none of them
};

/// What this device holds of the ward, for checks 2 and 7. A first download holds nothing.
struct HeldVersion
{
    std::optional<qint64> base;  ///< none for a ward not yet on the server
    DataKey key;
};

/// A version that passed every check, as the session takes it.
struct TakenVersion
{
    qint64 version;
    DataKey key;
    Document document;
    LandedMarks landed;
    QSet<Fingerprint> recipients;  ///< whom its header seals to
};

struct CheckedVersion
{
    VersionVerdict verdict;
    std::optional<TakenVersion> taken;  ///< set when the verdict is Accepted
};

/// The download checks, in the design's order. A download replaces nothing until they pass:
/// these read and decide, and the session takes only what they accept.
class VersionCheck
{
public:
    /// Checks 1 to 3, on a head's header line.
    static VersionVerdict checkHead(const QByteArray& headerLine, qint64 versionNumber,
                                    const Fingerprint& reader, const std::optional<HeldVersion>& held);

    /// Checks 1 to 7, on a fetched version's body. reader is this device, or an invite for a
    /// join. held is none for a first download, which skips checks 2 and 7.
    static CheckedVersion checkVersion(const QByteArray& body, qint64 versionNumber,
                                       const DeviceIdentity& reader, const std::optional<HeldVersion>& held);
```

```cpp
std::optional<QByteArray> sealedKeyFor(const WardHeader& header, const Fingerprint& reader)
{
    for (const Recipient& recipient : header.recipients())
    {
        if (recipient.fingerprint == reader)
        {
            return recipient.sealedKey;
        }
    }
    return std::nullopt;
}

QList<Fingerprint> fingerprintsOf(const WardHeader& header)
{
    QList<Fingerprint> fingerprints;
    for (const Recipient& recipient : header.recipients())
    {
        fingerprints.append(recipient.fingerprint);
    }
    return fingerprints;
}

struct HeaderVerdict
{
    VersionVerdict verdict;
    WardHeader header;
};

/// Checks 1 to 3. The rollback check comes before the names check, so a server restored to a
/// version from before this device joined reads as rolled back, not as the ward leaving it.
HeaderVerdict checkHeader(const QByteArray& headerLine, qint64 versionNumber,
                          const Fingerprint& reader, const std::optional<HeldVersion>& held)
{
    HeaderRead read = WardHeader::read(headerLine);
    if (read.status == HeaderStatus::Newer)
    {
        return HeaderVerdict{VersionVerdict::NewerFormat, read.header};
    }
    if (read.status == HeaderStatus::Unreadable)
    {
        return HeaderVerdict{VersionVerdict::Unreadable, read.header};
    }
    if (held.has_value() && held->base.has_value() && versionNumber < *held->base)
    {
        return HeaderVerdict{VersionVerdict::RolledBack, read.header};
    }
    if (read.header.recipients().isEmpty())
    {
        return HeaderVerdict{VersionVerdict::Deleted, read.header};
    }
    if (!sealedKeyFor(read.header, reader).has_value())
    {
        return HeaderVerdict{VersionVerdict::NotNamed, read.header};
    }
    return HeaderVerdict{VersionVerdict::Accepted, read.header};
}

}  // namespace

VersionVerdict VersionCheck::checkHead(const QByteArray& headerLine, qint64 versionNumber,
                                       const Fingerprint& reader, const std::optional<HeldVersion>& held)
{
    return checkHeader(headerLine, versionNumber, reader, held).verdict;
}

CheckedVersion VersionCheck::checkVersion(const QByteArray& body, qint64 versionNumber,
                                          const DeviceIdentity& reader, const std::optional<HeldVersion>& held)
{
    HeaderVerdict header = checkHeader(WardFile::headerLine(body), versionNumber, reader.fingerprint(), held);
    if (header.verdict != VersionVerdict::Accepted)
    {
        return CheckedVersion{header.verdict, std::nullopt};
    }

    std::optional<DataKey> key = reader.unseal(*sealedKeyFor(header.header, reader.fingerprint()));
    if (!key.has_value())
    {
        return CheckedVersion{VersionVerdict::Unreadable, std::nullopt};
    }

    std::optional<VersionPayload> payload = WardFile::decodeVersion(body, *key);
    if (!payload.has_value())
    {
        return CheckedVersion{VersionVerdict::Unreadable, std::nullopt};
    }

    const AccessList& access = payload->document.access();
    if (!access.matches(fingerprintsOf(header.header)))
    {
        return CheckedVersion{VersionVerdict::Unreadable, std::nullopt};
    }

    bool descends = !held.has_value()
        || *key == held->key
        || access.namesFormerKey(held->key.formerKeyHash());
    if (!descends)
    {
        return CheckedVersion{VersionVerdict::NotDescending, std::nullopt};
    }

    TakenVersion taken{versionNumber, *key, payload->document, payload->landed, access.recipientFingerprints()};
    return CheckedVersion{VersionVerdict::Accepted, taken};
}
```

```cpp
        return;
    }
    m_mustLook = true;
    sync();
}

SyncState WardSession::syncState() const
{
    if (m_noLongerShared)
    {
        return SyncState::NoLongerShared;
    }
    if (savesFailing())
    {
        return SyncState::SavesFailing;
    }
    return m_serverState;
}

/// The push carries the document as it stands: the base version plus every journal entry. It
/// rotates when its access list has lost anyone the base version seals to, so the new key goes
/// only to those remaining and the old key's hash joins the former keys. Its landed marks are
/// the base's, without devices the list no longer holds, and with this device's set to the last
/// sequence number given out.
void WardSession::startPush()
{
    AccessList access = m_document.access();
    QSet<Fingerprint> recipients = access.recipientFingerprints();
    DataKey key = m_key;
    if (m_base.has_value() && !recipients.contains(m_baseRecipients))
    {
        access.appendFormerKey(m_key.formerKeyHash());
        key = DataKey::generate();
    }
    qint64 mark = m_journal.lastSequence();
    LandedMarks landed = m_landed.keptFor(access.deviceFingerprints());
    landed.set(m_identity.fingerprint(), mark);
    m_pushInFlight = PushInFlight{key, recipients, access.formerKeys(), landed, mark};

    Document version = m_document;
    version.setAccess(access);
    QByteArray body = WardFile::encodeVersion(m_id, version, landed, key, access.recipients());
    if (m_base.has_value())
    {
        startCall(m_server->push(m_id, *m_base, body, m_identity));
    }
    else
    {
        startCall(m_server->create(m_id, body, m_identity));
    }
    connect(m_call, &ServerCall::answered, this, &WardSession::onPushAnswered);
}

void WardSession::startFetch()
{
    startCall(m_server->fetch(m_id));
    connect(m_call, &ServerCall::answered, this, &WardSession::onFetchAnswered);
}

void WardSession::startCall(ServerCall* call)
{
    call->setParent(this);
    m_call = call;
}

void WardSession::finishCall()
{
    m_call->deleteLater();
    m_call = nullptr;
}

/// Lets go of the call in flight when the session moves to another ward. Its outcome is
/// settled by the next look at that ward.
void WardSession::dropCall()
{
    if (m_call != nullptr)
    {
        disconnect(m_call, nullptr, this, nullptr);
        finishCall();
    }
    m_pushInFlight.reset();
}

/// A write is stored or it is not. One not stored - refused, or never answered - is settled
/// by looking: a newer version is replayed onto, a header without this device or a missing ward
/// is a removal, an unchanged head is a fault, and a push whose answer was lost is found landed
/// by its mark.
void WardSession::onPushAnswered(const ServerAnswer& answer)
{
    finishCall();
    PushInFlight push = *m_pushInFlight;
    m_pushInFlight.reset();
    if (answer.outcome == ServerOutcome::Stored)
    {
        pushLanded(push, *answer.version);
        return;
    }
    m_writeRefused = true;
    look();
}

void WardSession::onFetchAnswered(const ServerAnswer& answer)
{
    finishCall();
    bool settlingRefusal = m_writeRefused;
    m_writeRefused = false;
    switch (answer.outcome)
    {
    case ServerOutcome::Ward:
        if (settlingRefusal && m_base.has_value() && *answer.version == *m_base)
        {
            setServerState(SyncState::Faulted);
            break;
        }
        considerVersion(VersionCheck::checkVersion(answer.body, *answer.version, m_identity, held()));
        break;
    case ServerOutcome::Missing:
        notOnTheServer(settlingRefusal);
        break;
    case ServerOutcome::Unreached:
        setServerState(SyncState::Offline);
        break;
    case ServerOutcome::Fault:
    case ServerOutcome::Stored:
    case ServerOutcome::NotStored:
        setServerState(SyncState::Faulted);
        break;
    }
}

/// The push is the server's version now: its number is the base, its key the one the local
/// file is saved under, and the entries it carries leave the journal. A command made while it
/// was in flight sits above its mark and goes out with the next push.
void WardSession::pushLanded(const PushInFlight& push, qint64 version)
{
    m_base = version;
    m_key = push.key;
    m_baseRecipients = push.recipients;
    m_landed = push.landed;
    AccessList access = m_document.access();
    access.setFormerKeys(push.formerKeys);
    m_document.setAccess(access);
    m_journal.dropThrough(push.mark);
    setServerState(SyncState::Syncing);
    save();
    sync();
}

void WardSession::considerVersion(const CheckedVersion& checked)
{
    switch (checked.verdict)
    {
    case VersionVerdict::Accepted:
        take(*checked.taken);
        break;
    case VersionVerdict::Deleted:
    case VersionVerdict::NotNamed:
        becomeNoLongerShared();
        break;
    case VersionVerdict::NewerFormat:
        setServerState(SyncState::NewerFormat);
        break;
    case VersionVerdict::RolledBack:
        setServerState(SyncState::RolledBack);
        break;
    case VersionVerdict::Unreadable:
    case VersionVerdict::NotDescending:
        setServerState(SyncState::Unreadable);
        break;
    }
}

/// Takes a version that passed every check. The entries its landed mark covers leave the
/// journal, whoever published it, so a push whose answer never came is settled here; the
/// counter rises to the mark; the rest replays onto the version; and what results is saved and
/// pushed when anything remains to push.
void WardSession::take(const TakenVersion& version)
{
    qint64 mark = version.landed.markOf(m_identity.fingerprint());
    m_journal.dropThrough(mark);
    m_journal.raiseCounterTo(mark);
    m_base = version.version;
    m_key = version.key;
    m_baseRecipients = version.recipients;
    m_landed = version.landed;
    m_mustLook = false;
    m_downloading = false;
    replayOnto(version.document);
    setServerState(SyncState::Syncing);
    save();
    sync();
}

/// A ward this device has had from or given to the server, which the server no longer has, is
/// a removal, as is a first download of a ward it does not have. A ward not yet on the server
/// makes its first push, unless that push was just refused, which is a fault.
void WardSession::notOnTheServer(bool settlingRefusal)
{
    if (m_base.has_value() || m_downloading)
    {
        becomeNoLongerShared();
        return;
    }
    if (settlingRefusal)
    {
        setServerState(SyncState::Faulted);
        return;
    }
    m_mustLook = false;
    sync();
}

/// The ward stops pushing for good on this device: its unsent changes are dropped, its copy is
/// read-only, and the flag is saved so a device reopened offline still knows.
void WardSession::becomeNoLongerShared()
{
    m_noLongerShared = true;
    m_mustLook = false;
    m_journal.clear();
    clearUndoStack();
    if (!m_downloading)
    {
        save();
    }
    emit syncStateChanged();
}

void WardSession::setServerState(SyncState state)
{
    SyncState before = syncState();
    m_serverState = state;
    if (syncState() != before)
    {
        emit syncStateChanged();
    }
}

std::optional<HeldVersion> WardSession::held() const
{
    if (m_downloading)
    {
        return std::nullopt;
    }
    return HeldVersion{m_base, m_key};
}
```

gave to, the server, and a local save never rotates.

```cpp
/// The Ward Planning server in process, as the transport beneath HttpServer, so every client
/// test runs the wire encoding. It holds versions in memory, stores a write only when the
/// design says the server may, verifies every signature, and answers every refusal with one
/// error status, since the client tells refusals apart by looking, not by their codes.
///
/// Requests wait in arrival order until the test answers them, so a test steps its clients
/// with no timers.
class FakeServer : public Transport
{
public:
    FakeServer();

    TransportCall* send(const WireRequest& request) override;

    qsizetype pendingCount() const { return m_waiting.size(); }

    /// Processes the oldest waiting request, as the server receiving it would, and delivers its
    /// answer, which may send further requests.
    void answerNext();

    /// Answers requests until none waits, including those the answers send.
    void answerAll();

    /// While unreachable, nothing is processed and every request gets no answer.
    void setReachable(bool reachable) { m_reachable = reachable; }

    /// The next request processed is processed in full, and its answer never arrives.
    void dropNextReply() { m_dropNextReply = true; }

    /// The next request processed is refused and stores nothing, as a rate limit refuses it.
    void refuseNext() { m_refuseNext = true; }

    /// The document's current version becomes body under version, as a server bug, a restore,
    /// or a hostile operator might serve it.
    void serve(const DocumentId& id, qint64 version, const QByteArray& body);

    /// The server no longer has the document.
    void forget(const DocumentId& id) { m_documents.remove(id); }

    std::optional<qint64> versionOf(const DocumentId& id) const;

    /// The body that was current at version, for a test to inspect.
    QByteArray bodyAt(const DocumentId& id, qint64 version) const;

    const QList<FakeExchange>& exchanges() const { return m_exchanges; }

    /// The methods of the exchanges from index on, in order.
    QByteArrayList methodsSince(qsizetype index) const;

private:
    enum class ReadKind
    {
        Head,
        Version
    };

    struct StoredDocument
    {
        qint64 version;
        QByteArray body;
        QSet<Fingerprint> names;
        Fingerprint publisher;
        QDateTime published;
        QHash<qint64, QByteArray> history;
    };

    struct Waiting
    {
        WireRequest request;
        QPointer<TransportCall> call;
    };

    WireResponse process(const WireRequest& request);
    WireResponse post(const WireRequest& request);
    WireResponse put(const QByteArray& pathId, const WireRequest& request);
    WireResponse read(const QByteArray& pathId, ReadKind kind) const;
```

### `tests/server/FakeServer.cpp`

```cpp
#include "FakeServer.h"
#include "Base64Url.h"
#include "Crypto.h"
#include "SignedLine.h"

#include <QJsonArray>
#include <QJsonDocument>
#include <QJsonObject>
#include <QTimeZone>

namespace
{

/// What the server reads from a header: the document it names and the fingerprints it seals
/// to. Read on the server's own terms rather than through the app's strict reader, as a server
/// that supports a format before any app writes it would.
struct FakeHeader
{
    DocumentId id;
    QSet<Fingerprint> names;
};

std::optional<FakeHeader> readHeader(const QByteArray& line)
{
    QJsonParseError error;
    QJsonDocument parsed = QJsonDocument::fromJson(line, &error);
    if (error.error != QJsonParseError::NoError || !parsed.isObject())
    {
        return std::nullopt;
    }
    QJsonObject header = parsed.object();
    std::optional<DocumentId> id = DocumentId::fromString(header["document"].toString());
    if (!id.has_value() || !header["recipients"].isArray())
    {
        return std::nullopt;
    }
    QSet<Fingerprint> names;
    QJsonArray recipients = header["recipients"].toArray();
    for (const QJsonValue& recipient : recipients)
    {
        std::optional<Fingerprint> fingerprint = Fingerprint::fromString(recipient.toObject()["fingerprint"].toString());
        if (!fingerprint.has_value())
        {
            return std::nullopt;
        }
        names.insert(*fingerprint);
    }
    return FakeHeader{*id, names};
}

/// A write as the server reads it: its header, its signer and its signature.
struct SignedWrite
{
    FakeHeader header;
    Fingerprint signer;
    QByteArray verifyKey;
    QByteArray signature;
};

std::optional<SignedWrite> readSignedWrite(const WireRequest& request)
{
    int boundary = request.body.indexOf('\n');
    if (boundary < 0)
    {
        return std::nullopt;
    }
    std::optional<FakeHeader> header = readHeader(request.body.left(boundary));
    QList<QByteArray> keys = request.headers.value(WireHeader::Signer).split('.');
    if (!header.has_value() || keys.size() != 2)
    {
        return std::nullopt;
    }
    std::optional<QByteArray> publicKey = Base64Url::decode(QString::fromLatin1(keys[0]), 32);
    std::optional<QByteArray> verifyKey = Base64Url::decode(QString::fromLatin1(keys[1]), 32);
    std::optional<QByteArray> signature =
        Base64Url::decode(QString::fromLatin1(request.headers.value(WireHeader::Signature)), 64);
    if (!publicKey.has_value() || !verifyKey.has_value() || !signature.has_value())
    {
        return std::nullopt;
    }
    return SignedWrite{*header, Fingerprint::of(*publicKey, *verifyKey), *verifyKey, *signature};
}

std::optional<qint64> readDecimal(const QByteArray& text)
{
    bool ok = false;
    qint64 value = text.toLongLong(&ok);
    if (!ok || value < 0 || QByteArray::number(value) != text)
    {
        return std::nullopt;
    }
    return value;
}

WireResponse status(int code)
{
    WireResponse response;
    response.status = code;
    return response;
}

/// Every write the server does not store gets this answer, whatever the reason.
WireResponse refused()
{
    return status(400);
}

WireResponse withVersion(qint64 version)
{
    WireResponse response = status(200);
    response.headers.insert(WireHeader::Version, QByteArray::number(version));
    return response;
}

FakeServer::FakeServer()
    : m_clock(QDate(2026, 10, 17), QTime(12, 0), QTimeZone::utc())
{
}

TransportCall* FakeServer::send(const WireRequest& request)
{
    TransportCall* call = new TransportCall(nullptr);
    m_waiting.append(Waiting{request, call});
    return call;
}

void FakeServer::answerNext()
{
    Q_ASSERT_X(!m_waiting.isEmpty(), "FakeServer::answerNext", "no request is waiting");
    Waiting waiting = m_waiting.takeFirst();
    WireResponse response;
    if (m_reachable)
    {
        WireResponse processed = process(waiting.request);
        if (m_dropNextReply)
        {
            m_dropNextReply = false;
        }
        else
        {
            response = processed;
        }
    }
    m_exchanges.append(FakeExchange{waiting.request.method, waiting.request.path, response.status});
    if (!waiting.call.isNull())
    {
        emit waiting.call->finished(response);
    }
}

void FakeServer::answerAll()
{
    for (int answered = 0; !m_waiting.isEmpty(); ++answered)
    {
        Q_ASSERT_X(answered < 1000, "FakeServer::answerAll", "the clients keep calling");
        answerNext();
    }
}

void FakeServer::serve(const DocumentId& id, qint64 version, const QByteArray& body)
{
    auto stored = m_documents.constFind(id);
    Q_ASSERT_X(stored != m_documents.constEnd(), "FakeServer::serve", "the fake serves only a document it holds");
    std::optional<FakeHeader> header = readHeader(body.left(body.indexOf('\n')));
    QSet<Fingerprint> names;
    if (header.has_value())
    {
        names = header->names;
    }
    store(id, version, body, names, stored->publisher);
}

std::optional<qint64> FakeServer::versionOf(const DocumentId& id) const
{
    auto stored = m_documents.constFind(id);
    if (stored == m_documents.constEnd())
    {
        return std::nullopt;
    }
    return stored->version;
}

QByteArray FakeServer::bodyAt(const DocumentId& id, qint64 version) const
{
    auto stored = m_documents.constFind(id);
    Q_ASSERT_X(stored != m_documents.constEnd(), "FakeServer::bodyAt", "the fake holds no such document");
    return stored->history.value(version);
}

QByteArrayList FakeServer::methodsSince(qsizetype index) const
{
    QByteArrayList methods;
    for (qsizetype i = index; i < m_exchanges.size(); ++i)
    {
        methods.append(m_exchanges[i].method);

WireResponse FakeServer::process(const WireRequest& request)
{
    if (m_refuseNext)
    {
        m_refuseNext = false;
        return refused();
    }
    QList<QByteArray> path = request.path.split('/');
    if (request.method == "POST" && request.path == "/documents")
    {
        return post(request);
    }
    if (path.size() == 3 && path[1] == "documents" && request.method == "PUT")
    {
        return put(path[2], request);
    }
    if (path.size() == 3 && path[1] == "documents" && request.method == "GET")
    {
        return read(path[2], ReadKind::Version);
    }
    if (path.size() == 4 && path[1] == "documents" && path[3] == "head" && request.method == "GET")
    {
        return read(path[2], ReadKind::Head);
    }
    return refused();
}

/// Version 1 of a new document, stored when its id is new and it is signed by a device its own
/// header names.
WireResponse FakeServer::post(const WireRequest& request)
{
    std::optional<SignedWrite> write = readSignedWrite(request);
    bool storable = write.has_value()
        && !m_documents.contains(write->header.id)
        && write->header.names.contains(write->signer)
        && Crypto::verify(write->signature, SignedLine::create(write->header.id, request.body), write->verifyKey);
    if (!storable)
    {
        return refused();
    }
    store(write->header.id, 1, request.body, write->header.names, write->signer);
    return withVersion(1);
}

/// The next version, stored when its header is well formed and names this document, its signer
/// is named by the current header, and its base is the current version.
WireResponse FakeServer::put(const QByteArray& pathId, const WireRequest& request)
{
    std::optional<DocumentId> id = DocumentId::fromString(QString::fromLatin1(pathId));
    std::optional<SignedWrite> write = readSignedWrite(request);
    std::optional<qint64> base = readDecimal(request.headers.value(WireHeader::BaseVersion));
    if (!id.has_value() || !write.has_value() || !base.has_value() || write->header.id != *id)
    {
        return refused();
    }
    auto stored = m_documents.constFind(*id);
    bool storable = stored != m_documents.constEnd()
        && stored->names.contains(write->signer)
        && *base == stored->version
        && Crypto::verify(write->signature, SignedLine::push(*id, *base, request.body), write->verifyKey);
    if (!storable)
    {
        return refused();
    }
    qint64 version = stored->version + 1;
    store(*id, version, request.body, write->header.names, write->signer);
    return withVersion(version);
}

WireResponse FakeServer::read(const QByteArray& pathId, ReadKind kind) const
{
    std::optional<DocumentId> id = DocumentId::fromString(QString::fromLatin1(pathId));
    if (!id.has_value())
    {
        return refused();
    }
    auto stored = m_documents.constFind(*id);
    if (stored == m_documents.constEnd())
    {
        return status(404);
    }
    WireResponse response = withVersion(stored->version);
    response.headers.insert(WireHeader::Publisher, stored->publisher.toString().toLatin1());
    response.headers.insert(WireHeader::Published, stored->published.toString(Qt::ISODate).toLatin1());
    if (kind == ReadKind::Head)
    {
        response.body = stored->body.left(stored->body.indexOf('\n'));
    }
    else
    {
        response.body = stored->body;
    }
    return response;
}

void FakeServer::store(const DocumentId& id, qint64 version, const QByteArray& body,
                       const QSet<Fingerprint>& names, const Fingerprint& publisher)
{
    m_clock = m_clock.addSecs(60);
    QHash<qint64, QByteArray> history;
    auto existing = m_documents.constFind(id);
    if (existing != m_documents.constEnd())
    {
        history = existing->history;
    }
    history.insert(version, body);
    m_documents.insert(id, StoredDocument{version, body, names, publisher, m_clock, history});
}
```

```cpp
ServerAnswer answerOf(ServerCall* call, RecordingTransport& transport, const WireResponse& response)
{
    std::unique_ptr<ServerCall> owned(call);

    QObject::connect(owned.get(), &ServerCall::answered, &catcher, &AnswerCatcher::catchAnswer);
    transport.answer(0, response);

    }
    return response;
```

## Open questions for the user

The design is silent on these, or two of its sentences pull different ways; each states the
choice this plan makes.

1. **A look is a fetch**, not a head read and then a fetch: the fetch shows the head and carries
   the landed mark that settles a write whose answer was lost. A write not stored is followed by
   a look at once; when that look gets no answer the ward is `Offline` until the next retry.
2. **Where the access list lives.** Plan 1's commands run on `Document&`, and plan 2 keeps the
   access list in `WardSession::m_access`, where no command can reach it. This plan moves it
   into `Document` (`access()` / `setAccess()`, left out of the `ward` part's JSON and written as
   the `access` part), so an access-list change replays like any command, as the design asks.
   The other way is for `execute` and `refusal` to take a ward of document and access list
   together, which changes plan 1's contract for every command. My recommendation is the move
   into `Document`. Which do you want?
3. **Dropped unsent changes.** On becoming no longer shared, the journal is emptied; the read-only
   copy still shows those changes, since there is no base copy to return to.
4. **Wording for the only admin stepping down or leaving:** *You are the only admin. Make someone
   else an admin first.*
5. **Wording when an edit races a confirmed Leave:** *This ward cannot be changed while this device
   leaves it.*
6. **The live channel's wire** (an open point). Proposed: a WebSocket at
   `/documents/{id}/channel`, its signature in `ward-signer` and `ward-signature` on the upgrade,
   JSON text messages `{"present":[...]}`, `{"arrived":fp}`, `{"departed":fp}`,
   `{"version":n}`, a 30-second heartbeat, a missed one or a close ending presence, and a
   reconnect on the next retry trigger. Task 6's `HttpServer` part waits on this.
7. **Head polling as the channel's fallback** (an open point): none in this plan.
8. **`GET /releases/latest`'s body:** proposed `{"version":"1.2.0","windows":"<url>","macos":"<url>"}`.
9. **The built-in server address.**
10. **A device invitation's file name:** proposed `Tanglewood Ward - a device invitation.wardinvite`.
11. **Access notice lines:** an invite that leaves the list with a device or user joining reads as
    *used*, and otherwise as *withdrawn*?
12. **Removing yourself** is refused with *To stop using this ward, use Leave.*, the design's
    wording for removing your last device.
13. **When a call counts as unanswered:** a 30-second transfer timeout in `NetworkTransport`.
14. **`FakeServer` answers every refusal, and an unknown route, with one error status**, since
    the client tells refusals apart only by the look that follows.
