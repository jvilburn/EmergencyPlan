# Server Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-with-review to implement this plan task-by-task.

**Goal:** The Ward Planning server: a Cloudflare Worker with one SQLite-backed Durable Object per
ward that stores each ward's current version under the version condition, checks every write's
signature and header, and holds the live channel of every device that has the ward open.

**Architecture:** `Ward` is the Durable Object for one ward. It holds the current version under
one storage key, answers create, head, fetch and push, and holds the ward's WebSockets through the
hibernation API, each tagged with its device's fingerprint. `wire.ts` reads what travels: base64url,
the header, the body's framing, the signer, the signed lines, the routes. The Worker in `index.ts`
limits each address, serves the release calls, and hands each document call to the `Ward` named by
its document id.

**Tech Stack:** TypeScript 7.0.2, Cloudflare Workers with SQLite-backed Durable Objects
(compatibility date 2026-11-01), wrangler 4.156.1, `@noble/hashes` 2.4.0 for BLAKE2b, WebCrypto
Ed25519 for signatures, Vitest 5.0.5 with `@cloudflare/vitest-plugin` 1.4.12, which runs the tests
inside workerd.

**Design authority:** `docs/SHARED_WARD_DESIGN.md`: *What the server is*, *The live channel*, *Who
is here*, *File format* (framing, header, fingerprints, primitives), *Hosting notes*. Section names
in *italics* are its sections. The known answers are the ones `docs/plans/2026-10-17-ward-file.md`
(fingerprint) and `docs/plans/2026-10-17-sharing.md` (signed lines) pin for the app.

```ts
import { blake2b } from "@noble/hashes/blake2.js";

/** Byte lengths of the binary values on the wire, each sent as base64url without padding. */
export const IdBytes = 16;
export const NonceBytes = 24;
export const FingerprintBytes = 16;
export const SealedKeyBytes = 80;
export const KeyBytes = 32;
export const SignatureBytes = 64;

/** The one header format this server stores. A new format is supported here before any app writes it. */
export const Format = 1;

const encoder = new TextEncoder();
const FingerprintPersonalization = personalization("wp-fingerprint");

/** Base64url without padding, as every binary value on the wire is. */
export function encode(bytes: Uint8Array): string
{
    let binary = "";
    for (const byte of bytes)
    {
        binary += String.fromCharCode(byte);
    }
    return btoa(binary).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

/** The bytes text spells when it is the canonical base64url of exactly length bytes; null otherwise. */
export function decode(text: unknown, length: number): Uint8Array | null
{
    if (typeof text !== "string"
        || text.length !== Math.ceil(length * 4 / 3)
        || !/^[A-Za-z0-9_-]*$/.test(text))
    {
        return null;
    }
    const binary = atob(text.replace(/-/g, "+").replace(/_/g, "/"));
    const bytes = Uint8Array.from(binary, (character) => character.charCodeAt(0));
    return encode(bytes) === text ? bytes : null;
}

/** What the server reads from a header: the document it names and the fingerprints it seals to. */
export interface Header
{
    document: string;
    recipients: string[];
}

/** The header line read strictly as format 1: exactly its four keys, each well formed. */
export function readHeader(line: string): Header | null
{
    let json: unknown;
    try
    {
        json = JSON.parse(line);
    }
    catch
    {
        return null;
    }
    if (!hasExactly(json, ["format", "document", "nonce", "recipients"])
        || json.format !== Format
        || decode(json.document, IdBytes) === null
        || decode(json.nonce, NonceBytes) === null
        || !Array.isArray(json.recipients))
    {
        return null;
    }
    const recipients: string[] = [];
    for (const recipient of json.recipients)
    {
        if (!hasExactly(recipient, ["fingerprint", "sealedKey"])
            || decode(recipient.fingerprint, FingerprintBytes) === null
            || decode(recipient.sealedKey, SealedKeyBytes) === null)
        {
            return null;
        }
        recipients.push(recipient.fingerprint as string);
    }
    return { document: json.document as string, recipients };
}

/** A version as it travels: the header line, one `\n`, then the payload. */
export interface Body
{
    bytes: Uint8Array;
    headerLength: number;
    header: Header;
}

/** The body framed and its header well formed; null otherwise. */
export function readBody(bytes: Uint8Array): Body | null
{
    const headerLength = bytes.indexOf(0x0a);
    if (headerLength < 0)
    {
        return null;
    }
    let line: string;
    try
    {
        line = new TextDecoder("utf-8", { fatal: true, ignoreBOM: true }).decode(bytes.subarray(0, headerLength));
    }
    catch
    {
        return null;
    }
    const header = readHeader(line);
    if (header === null)
    {
        return null;
    }
    return { bytes, headerLength, header };
}

/** Who signed a request, from its `Ward-Signer` and `Ward-Signature` headers. */
export interface Signer
{
    fingerprint: string;
    verifyKey: Uint8Array;
    signature: Uint8Array;
}

/** The signer, when both headers are well formed; null otherwise. */
export function readSigner(headers: Headers): Signer | null
{
    const keys = (headers.get("Ward-Signer") ?? "").split(".");
    if (keys.length !== 2)
    {
        return null;
    }
    const publicKey = decode(keys[0], KeyBytes);
    const verifyKey = decode(keys[1], KeyBytes);
    const signature = decode(headers.get("Ward-Signature"), SignatureBytes);
    if (publicKey === null || verifyKey === null || signature === null)
    {
        return null;
    }
    return { fingerprint: encode(fingerprintOf(publicKey, verifyKey)), verifyKey, signature };
}

/** A device's fingerprint: 16-byte BLAKE2b of its X25519 public key then its Ed25519 verify key, personalised `wp-fingerprint`. */
export function fingerprintOf(publicKey: Uint8Array, verifyKey: Uint8Array): Uint8Array
{
    const keys = new Uint8Array(publicKey.length + verifyKey.length);
    keys.set(publicKey);
    keys.set(verifyKey, publicKey.length);
    return blake2b(keys, { dkLen: FingerprintBytes, personalization: FingerprintPersonalization });
}

/** The line a `create` (base 0) or a `push` signs. */
export function writeLine(call: "create" | "push", document: string, base: number, body: Body): string
{
    const header = body.bytes.subarray(0, body.headerLength);
    const payload = body.bytes.subarray(body.headerLength + 1);
    return `wardplanning-v1 ${call} ${document} ${base} ${hash(header)} ${hash(payload)}`;
}

/** The line opening the live channel signs, with `-` for the fields it lacks. */
export function channelLine(document: string): string
{
    return `wardplanning-v1 channel ${document} - - -`;
}

/** Whether the signer's signature over line verifies. A key that is not a valid point does not verify. */
export async function verifies(signer: Signer, line: string): Promise<boolean>
{
    try
    {
        const key = await crypto.subtle.importKey("raw", signer.verifyKey, { name: "Ed25519" }, false, ["verify"]);
        return await crypto.subtle.verify({ name: "Ed25519" }, key, signer.signature, encoder.encode(line));
    }
    catch
    {
        return false;
    }
}

/** A version number as `Ward-Base-Version` carries it: a decimal integer with no sign or leading zero. */
export function readVersion(text: string | null): number | null
{
    if (text === null || !/^(0|[1-9][0-9]{0,14})$/.test(text))
    {
        return null;
    }
    return Number(text);
}

/** Where a request goes, read from its method and path alone. */
export type Route =
    | { kind: "create" }
    | { kind: "head"; document: string }
    | { kind: "version"; document: string }
    | { kind: "push"; document: string }
    | { kind: "channel"; document: string }
    | { kind: "releases" }
    | { kind: "download" };

export function routeOf(method: string, path: string): Route | null
{
    const parts = path.split("/");
    if (method === "POST" && path === "/documents")
    {
        return { kind: "create" };
    }
    if (method === "GET" && path === "/releases/latest")
    {
        return { kind: "releases" };
    }
    if (method === "GET" && path === "/download")
    {
        return { kind: "download" };
    }
    if (parts.length === 3 && parts[1] === "documents" && method === "GET")
    {
        return { kind: "version", document: parts[2] };
    }
    if (parts.length === 3 && parts[1] === "documents" && method === "PUT")
    {
        return { kind: "push", document: parts[2] };
    }
    if (parts.length === 4 && parts[1] === "documents" && parts[3] === "head" && method === "GET")
    {
        return { kind: "head", document: parts[2] };
    }
    if (parts.length === 4 && parts[1] === "documents" && parts[3] === "channel" && method === "GET")
    {
        return { kind: "channel", document: parts[2] };
    }
    return null;
}

/** An answer with no body. */
export function status(code: number): Response
{
    return new Response(null, { status: code });
}

/** An answer carrying the current version, as a stored write and a `412` do. */
export function withVersion(code: number, version: number): Response
{
    return new Response(null, { status: code, headers: { "Ward-Version": String(version) } });
}

function hash(bytes: Uint8Array): string
{
    return encode(blake2b(bytes, { dkLen: 32 }));
}

/** A BLAKE2b personalisation: the name zero-padded to 16 bytes. */
function personalization(name: string): Uint8Array
{
    const bytes = new Uint8Array(16);
    bytes.set(encoder.encode(name));
    return bytes;
}

function hasExactly(value: unknown, keys: string[]): value is Record<string, unknown>
{
    if (typeof value !== "object" || value === null || Array.isArray(value))
    {
        return false;
    }
    const actual = Object.keys(value);
    return actual.length === keys.length && keys.every((key) => actual.includes(key));
}
```

**Step 4: `server/src/ward.ts`**

```ts
import { DurableObject } from "cloudflare:workers";
import {
    Body,
    Signer,
    channelLine,
    readBody,
    readSigner,
    readVersion,
    routeOf,
    status,
    verifies,
    withVersion,
    writeLine,
} from "./wire";

/** The current version of one ward, which is all the server keeps of it. */
interface Stored
{
    version: number;
    body: Uint8Array;
    headerLength: number;
    recipients: string[];
    publisher: string;
    published: string;
}

const CurrentKey = "current";

/**
 * One ward: its current version, the version condition on every write, and the live channel of
 * every device holding it open.
 *
 * A Durable Object runs one event at a time, but another request can run while this one awaits.
 * So each call does all of its awaiting first, the signature check, and from reading the current
 * version to storing the next it runs straight through, which is what makes two writes from one
 * base impossible.
 */
export class Ward extends DurableObject<Env>
{
    async fetch(request: Request): Promise<Response>
    {
        const route = routeOf(request.method, new URL(request.url).pathname);
        switch (route?.kind)
        {
            case "create":
                return this.create(request);
            case "push":
                return this.push(request, route.document);
            case "head":
                return this.read(false);
            case "version":
                return this.read(true);
            case "channel":
                return this.open(request, route.document);
            default:
                return status(404);
        }
    }

    /** Clients send nothing on the channel; their pings are protocol frames the platform answers. */
    webSocketMessage(): void
    {
    }

    webSocketClose(socket: WebSocket): void
    {
        this.leave(socket);
    }

    webSocketError(socket: WebSocket): void
    {
        this.leave(socket);
    }

    /** Version 1, stored when no version exists and the header it carries names its signer. */
    private async create(request: Request): Promise<Response>
    {
        const body = readBody(new Uint8Array(await request.arrayBuffer()));
        const signer = readSigner(request.headers);
        if (body === null || signer === null)
        {
            return status(400);
        }
        const signed = await verifies(signer, writeLine("create", body.header.document, 0, body));
        if (this.current() !== undefined)
        {
            return status(409);
        }
        if (!signed || !body.header.recipients.includes(signer.fingerprint))
        {
            return status(403);
        }
        this.store(1, body, signer);
        return withVersion(201, 1);
    }

    /** The next version, stored when the current header names its signer and it builds on the current version. */
    private async push(request: Request, document: string): Promise<Response>
    {
        const body = readBody(new Uint8Array(await request.arrayBuffer()));
        const signer = readSigner(request.headers);
        const base = readVersion(request.headers.get("Ward-Base-Version"));
        if (body === null || signer === null || base === null || body.header.document !== document)
        {
            return status(400);
        }
        const signed = await verifies(signer, writeLine("push", document, base, body));
        const current = this.current();
        if (current === undefined)
        {
            return status(404);
        }
        if (!signed || !current.recipients.includes(signer.fingerprint))
        {
            return status(403);
        }
        if (base !== current.version)
        {
            return withVersion(412, current.version);
        }
        const version = current.version + 1;
        this.store(version, body, signer);
        for (const socket of this.ctx.getWebSockets())
        {
            if (!body.header.recipients.includes(this.fingerprintOf(socket)))
            {
                socket.close(1000, "This device is no longer named by the ward");
            }
        }
        this.tellEveryone(version);
        return withVersion(200, version);
    }

    /** The head, or the whole current version. */
    private read(withPayload: boolean): Response
    {
        const current = this.current();
        if (current === undefined)
        {
            return status(404);
        }
        const body = withPayload ? current.body : current.body.subarray(0, current.headerLength);
        return new Response(body, {
            status: 200,
            headers: {
                "Ward-Version": String(current.version),
                "Ward-Publisher": current.publisher,
                "Ward-Published": current.published,
            },
        });
    }

    /** Opens a live channel for a device the current header names, replacing any it already has open. */
    private async open(request: Request, document: string): Promise<Response>
    {
        const signer = readSigner(request.headers);
        if (signer === null || request.headers.get("Upgrade")?.toLowerCase() !== "websocket")
        {
            return status(400);
        }
        const signed = await verifies(signer, channelLine(document));
        const current = this.current();
        if (current === undefined)
        {
            return status(404);
        }
        if (!signed || !current.recipients.includes(signer.fingerprint))
        {
            return status(403);
        }
        for (const old of this.ctx.getWebSockets(signer.fingerprint))
        {
            old.close(1000, "Replaced by a newer channel from this device");
        }
        const pair = new WebSocketPair();
        this.ctx.acceptWebSocket(pair[1], [signer.fingerprint]);
        this.tellEveryone(current.version);
        return new Response(null, { status: 101, webSocket: pair[0] });
    }

    private leave(socket: WebSocket): void
    {
        const current = this.current();
        if (current !== undefined)
        {
            this.tellEveryone(current.version, socket);
        }
    }

    /** Sends every open channel, but the one leaving, who is here, in sorted order, and the current version. */
    private tellEveryone(version: number, leaving?: WebSocket): void
    {
        const open = this.ctx.getWebSockets().filter((socket) => socket !== leaving && socket.readyState === WebSocket.OPEN);
        const present = [...new Set(open.map((socket) => this.fingerprintOf(socket)))].sort();
        const message = JSON.stringify({ present, version });
        for (const socket of open)
        {
            socket.send(message);
        }
    }

    /** The fingerprint a channel was opened under, its one tag. */
    private fingerprintOf(socket: WebSocket): string
    {
        return this.ctx.getTags(socket)[0];
    }

    private current(): Stored | undefined
    {
        return this.ctx.storage.kv.get<Stored>(CurrentKey);
    }

    private store(version: number, body: Body, signer: Signer): void
    {
        const stored: Stored = {
            version,
            body: body.bytes,
            headerLength: body.headerLength,
            recipients: body.header.recipients,
            publisher: signer.fingerprint,
            published: new Date().toISOString().replace(/\.\d{3}Z$/, "Z"),
        };
        this.ctx.storage.kv.put(CurrentKey, stored);
    }
}
```

```ts
import { env } from "cloudflare:workers";
import { IdBytes, NonceBytes, SealedKeyBytes, channelLine, encode, fingerprintOf, readBody, writeLine } from "../src/wire";

/** A device as the server sees one: two public keys, a fingerprint, and a signing key to sign with. */
export interface Device
{
    publicKey: Uint8Array;
    verifyKey: Uint8Array;
    signingKey: CryptoKey;
    fingerprint: string;
}

export async function newDevice(): Promise<Device>
{
    const pair = (await crypto.subtle.generateKey({ name: "Ed25519" }, true, ["sign", "verify"])) as CryptoKeyPair;
    const verifyKey = new Uint8Array((await crypto.subtle.exportKey("raw", pair.publicKey)) as ArrayBuffer);
    const publicKey = random(32);
    return { publicKey, verifyKey, signingKey: pair.privateKey, fingerprint: encode(fingerprintOf(publicKey, verifyKey)) };
}

export function newDocument(): string
{
    return encode(random(IdBytes));
}

export function random(length: number): Uint8Array
{
    return crypto.getRandomValues(new Uint8Array(length));
}

/** A version of document sealed to recipients, with a payload of random bytes. */
export function version(document: string, recipients: Device[], payload: Uint8Array = random(64)): Uint8Array
{
    return framed(JSON.stringify({
        format: 1,
        document,
        nonce: encode(random(NonceBytes)),
        recipients: recipients.map((device) => ({ fingerprint: device.fingerprint, sealedKey: encode(random(SealedKeyBytes)) })),
    }), payload);
}

/** A header line and a payload, framed as a body. */
export function framed(header: string, payload: Uint8Array): Uint8Array
{
    const line = new TextEncoder().encode(header + "\n");
    const bytes = new Uint8Array(line.length + payload.length);
    bytes.set(line);
    bytes.set(payload, line.length);
    return bytes;
}

/** The `Ward-Signer` and `Ward-Signature` headers of device signing line. */
export async function signed(device: Device, line: string): Promise<Record<string, string>>
{
    const signature = await crypto.subtle.sign({ name: "Ed25519" }, device.signingKey, new TextEncoder().encode(line));
    return {
        "Ward-Signer": `${encode(device.publicKey)}.${encode(device.verifyKey)}`,
        "Ward-Signature": encode(new Uint8Array(signature)),
    };
}

/** The Ward object holding document, as the Worker reaches it. */
export function ward(document: string): DurableObjectStub
{
    return env.WARD.get(env.WARD.idFromName(document));
}

const origin = "https://ward.test";

export async function post(device: Device, body: Uint8Array): Promise<Response>
{
    const parsed = readBody(body);
    const document = parsed === null ? newDocument() : parsed.header.document;
    const headers = parsed === null ? {} : await signed(device, writeLine("create", document, 0, parsed));
    return ward(document).fetch(`${origin}/documents`, { method: "POST", headers, body });
}

export async function put(device: Device, document: string, base: number, body: Uint8Array): Promise<Response>
{
    const parsed = readBody(body);
    const headers = parsed === null ? {} : await signed(device, writeLine("push", document, base, parsed));
    return ward(document).fetch(`${origin}/documents/${document}`, {
        method: "PUT",
        headers: { ...headers, "Ward-Base-Version": String(base) },
        body,
    });
}

export function head(document: string): Promise<Response>
{
    return ward(document).fetch(`${origin}/documents/${document}/head`);
}

export function get(document: string): Promise<Response>
{
    return ward(document).fetch(`${origin}/documents/${document}`);
}

/** The fingerprints of devices, as a channel message lists them. */
export function everyone(...devices: Device[]): string[]
{
    return devices.map((device) => device.fingerprint).sort();
}

/** What a channel has been told: who is here, and the current version. */
export interface Presence
{
    present: string[];
    version: number;
}

/** An open live channel, with the messages it has received in order. */
export class Channel
{
    private messages: Presence[] = [];
    private waiting: ((message: Presence) => void)[] = [];
    readonly closed: Promise<number>;

    constructor(readonly socket: WebSocket)
    {
        socket.addEventListener("message", (event) =>
        {
            const message = JSON.parse(event.data as string) as Presence;
            const next = this.waiting.shift();
            if (next !== undefined)
            {
                next(message);
            }
            else
            {
                this.messages.push(message);
            }
        });
        this.closed = new Promise((resolve) => socket.addEventListener("close", (event) => resolve(event.code)));
        socket.accept();
    }

    /** The next message, waiting for it when none has arrived. */
    next(): Promise<Presence>
    {
        const message = this.messages.shift();
        if (message !== undefined)
        {
            return Promise.resolve(message);
        }
        return new Promise((resolve) => this.waiting.push(resolve));
    }

    close(): void
    {
        this.socket.close(1000, "Closed by the test");
    }
}

/** Opens document's live channel as device, answering the refusal when it is refused. */
export async function open(device: Device, document: string, line: string = channelLine(document)): Promise<Channel | Response>
{
    const response = await ward(document).fetch(`${origin}/documents/${document}/channel`, {
        headers: { ...(await signed(device, line)), Upgrade: "websocket" },
    });
    return response.webSocket === null ? response : new Channel(response.webSocket);
}

/** Opens a channel that must be accepted. */
export async function opened(device: Device, document: string): Promise<Channel>
{
    const channel = await open(device, document);
    if (!(channel instanceof Channel))
    {
        throw new Error(`the channel was refused with ${channel.status}`);
    }
    return channel;
}

/** A ward created by its first device, with every device named. */
export async function created(devices: Device[]): Promise<string>
{
    const document = newDocument();
    const response = await post(devices[0], version(document, devices));
    if (response.status !== 201)
    {
        throw new Error(`the ward was not created: ${response.status}`);
    }
    return document;
}
```

```ts
import releases from "./releases.json";
import { IdBytes, Route, decode, readBody, routeOf, status } from "./wire";

export { Ward } from "./ward";

/**
 * The Worker in front of the wards: it limits each address, answers the release calls itself,
 * and hands every document call to the Ward object named by its document id.
 */
export default {
    async fetch(request: Request, env: Env): Promise<Response>
    {
        const route = routeOf(request.method, new URL(request.url).pathname);
        if (route === null)
        {
            return status(404);
        }
        const limit = limitOf(route, env);
        if (limit !== null && !(await limit.limit({ key: request.headers.get("CF-Connecting-IP") ?? "" })).success)
        {
            return status(429);
        }
        switch (route.kind)
        {
            case "releases":
                return Response.json(releases);
            case "download":
                return downloadPage();
            case "create":
            {
                const bytes = new Uint8Array(await request.arrayBuffer());
                const body = readBody(bytes);
                if (body === null)
                {
                    return status(400);
                }
                return wardOf(env, body.header.document).fetch(request.url, { method: "POST", headers: request.headers, body: bytes });
            }
            default:
                if (decode(route.document, IdBytes) === null)
                {
                    // A push's header cannot name a malformed id, so a push to one is malformed.
                    return status(route.kind === "push" ? 400 : 404);
                }
                return wardOf(env, route.document).fetch(request);
        }
    },
} satisfies ExportedHandler<Env>;

/** The limit a call counts against: creating a document, or reading one. Pushes and channels are signed by key holders. */
function limitOf(route: Route, env: Env): RateLimit | null
{
    switch (route.kind)
    {
        case "create":
            return env.CREATE_LIMIT;
        case "head":
        case "version":
            return env.READ_LIMIT;
        default:
            return null;
    }
}

function wardOf(env: Env, document: string): DurableObjectStub
{
    return env.WARD.get(env.WARD.idFromName(document));
}
```

```ts
import { exports } from "cloudflare:workers";
import { describe, expect, it } from "vitest";
import { readBody, writeLine } from "../src/wire";
import { framed, newDevice, newDocument, random, signed, version } from "./clients";

const origin = "https://ward.test";

/** A request to the Worker from address, as Cloudflare's edge passes it on. */
function fromAddress(address: string, path: string, init: RequestInit = {}): Promise<Response>
{
    return exports.default.fetch(new Request(`${origin}${path}`, {
        ...init,
        headers: { ...(init.headers as Record<string, string>), "CF-Connecting-IP": address },
    }));
}

async function create(address: string, document: string): Promise<Response>
{
    const alice = await newDevice();
    const body = version(document, [alice]);
    const headers = await signed(alice, writeLine("create", document, 0, readBody(body)!));
    return fromAddress(address, "/documents", { method: "POST", headers, body });
}

describe("routing", () =>
{
    it("hands a create to the ward its header names, and reads reach the same ward", async () =>
    {
        const document = newDocument();
        expect((await create("192.0.2.1", document)).status).toBe(201);
        const head = await fromAddress("192.0.2.1", `/documents/${document}/head`);
        expect(head.status).toBe(200);
        expect(head.headers.get("Ward-Version")).toBe("1");
        expect((await fromAddress("192.0.2.1", `/documents/${document}`)).status).toBe(200);
    });

    it("answers a create whose body cannot name a ward with 400", async () =>
    {
        const answer = await fromAddress("192.0.2.2", "/documents", { method: "POST", body: framed("{}", random(8)) });
        expect(answer.status).toBe(400);
    });

    it("answers a malformed id with 404 for a read or a channel and 400 for a push, and an unknown route with 404", async () =>
    {
        expect((await fromAddress("192.0.2.3", "/documents/not-an-id/head")).status).toBe(404);
        expect((await fromAddress("192.0.2.3", "/documents/not-an-id")).status).toBe(404);
        expect((await fromAddress("192.0.2.3", "/documents/not-an-id/channel")).status).toBe(404);
        expect((await fromAddress("192.0.2.3", "/documents/not-an-id", { method: "PUT", body: "x" })).status).toBe(400);
        expect((await fromAddress("192.0.2.3", "/documents", { method: "GET" })).status).toBe(404);
        expect((await fromAddress("192.0.2.3", "/")).status).toBe(404);
    });
});

describe("limits by address", () =>
{
    it("refuses an address's eleventh create in a minute with 429, and not another address's", async () =>
    {
        for (let i = 0; i < 10; ++i)
        {
            expect((await create("198.51.100.1", newDocument())).status).toBe(201);
        }
        const document = newDocument();
        expect((await create("198.51.100.1", document)).status).toBe(429);
        expect((await fromAddress("198.51.100.1", `/documents/${document}/head`)).status).toBe(404);
        expect((await create("198.51.100.2", newDocument())).status).toBe(201);
    });

    it("refuses an address's six hundred and first read in a minute with 429, and still takes its pushes", async () =>
    {
        const document = newDocument();
        const reads = await Promise.all(Array.from({ length: 600 }, () => fromAddress("203.0.113.1", `/documents/${document}/head`)));
        expect(reads.every((read) => read.status === 404)).toBe(true);
        expect((await fromAddress("203.0.113.1", `/documents/${document}`)).status).toBe(429);
        expect((await fromAddress("203.0.113.1", `/documents/${document}`, { method: "PUT", body: "x" })).status).toBe(400);
        expect((await fromAddress("203.0.113.2", `/documents/${document}`)).status).toBe(404);
    });
});

describe("releases", () =>
{
    it("serves the latest release and a download page linking its installers", async () =>
    {
        const latest = await fromAddress("192.0.2.9", "/releases/latest");
        expect(latest.status).toBe(200);
        const release = await latest.json() as { version: string; windows: string; macos: string };
        expect(Object.keys(release).sort()).toEqual(["macos", "version", "windows"]);

        const page = await (await fromAddress("192.0.2.9", "/download")).text();
        expect(page).toContain(`href="${release.windows}"`);
        expect(page).toContain(`href="${release.macos}"`);
    });
});
```

```markdown
# Ward Planning server

The server the app shares wards through: a Cloudflare Worker with one SQLite-backed Durable Object
per ward. Its wire is specified in `docs/SHARED_WARD_DESIGN.md` under *What the server is* and
*The live channel*; the server holds ciphertext and fingerprints only.

## Layout

- `src/index.ts`: the Worker. Limits each address, serves `/releases/latest` and `/download`, and
  hands each `/documents` call to the ward's object.
- `src/ward.ts`: the `Ward` Durable Object, one per ward: the current version, the version
  condition, and the live channels.
- `src/wire.ts`: base64url, the header, the body's framing, the signer, the signed lines, the
  routes.
- `src/releases.json`: the current release.
- `test/`: Vitest tests that run inside workerd.

## Developing

From `server/`:

- `npm install`
- `npm run check`: generates `worker-configuration.d.ts` from `wrangler.jsonc`, then type-checks.
- `npm test`: runs every test locally; nothing reaches Cloudflare.
- `npm run dev`: serves the Worker at `http://localhost:8787`, with local storage under
  `.wrangler/`. Point the app's server override there to use it.

## Deploying

- `npx wrangler login`, once per machine, as an account member.
- `npm run deploy` publishes the development Worker, `ward-planning-dev`, at its `workers.dev`
  address.
- `npx wrangler tail` streams the deployed Worker's logs.

## Where the data is

Each ward is one `Ward` object, named by its document id (`idFromName`), in the Worker's `WARD`
namespace. It keeps one storage value, `current`: the version number, the body exactly as pushed
(header line, `\n`, payload), the header's length, the fingerprints the header seals to, the
publisher's fingerprint and the publish time.

## Releasing the app

Edit `src/releases.json` to the new version and its installers' addresses, then `npm run deploy`.

## Moving to another host

Any server that implements the wire in *What the server is* and *The live channel* can take over
at the same domain. The app's conformance suite checks one: run it with
`WARD_PLANNING_SERVER_URL` set to the new server.
```

## Open questions for the user

The design is silent on these; each states the choice this plan makes.

1. **TypeScript follows `docs/CODING_STYLE.md`**: Allman braces, braces always, leading operators.
   This is unusual for TypeScript, and no formatter is configured to enforce it.
2. **The header is read strictly as format 1**: exactly `format`, `document`, `nonce` and
   `recipients`, and exactly `fingerprint` and `sealedKey` in each recipient, every value its
   exact length. A new format needs a server deploy before any app writes it, as *File format*
   says.
3. **Rate limits:** 10 creates and 600 reads a minute per address. Cloudflare counts them per
   location and approximately, which suits an abuse limit. The docs do not say whether the
   rate-limit binding is on the Workers Free plan; Task 4's deploy shows it.
4. **`releases.json`** names `v1.0.1` (the version in `installer.iss`) and GitHub release URLs on
   `jvilburn/EmergencyPlan` that are a guess, including a macOS installer that may not exist.
5. **A malformed id in the path** is a `404` for a read or a channel, and a `400` for a push,
   whose header cannot name such an id.
6. **The present list is sorted**, so the same set is always the same message.
7. **A version too large for one storage value** (the 2 MB limit) fails as a `500`, which the
   client treats as a fault.
8. **Not in this plan:** the production Worker on the real domain (no domain is chosen), the
   scheduled export of ciphertext to a second provider, and a restore tool. Each could be a task
   here or its own plan.
