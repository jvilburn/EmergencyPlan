# Auto-Load Last Document on Startup

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Automatically reopen the most recently used document when the app starts, so it feels like the app never closed.

**Architecture:** The existing `settings.json` (in `QStandardPaths::CacheLocation`) already stores `defaultLat`/`defaultLng`. Add a `lastDocumentPath` field. Save the path whenever `filePathChanged` fires. On startup, load it silently. If the file is missing, silently start with a new document (no error dialog).

**Tech Stack:** Qt 6 / C++17, existing `MainWindow` settings helpers + `DocumentManager`

### Task 1: Save Last Document Path to Settings

The existing `saveDefaultLocation` overwrites `settings.json` with only lat/lng. Refactor the settings helpers to read-modify-write so multiple keys can coexist.

**Files:**
- Modify: `src/widgets/MainWindow.cpp` (`saveDefaultLocation`, add `saveLastDocumentPath`)
- Modify: `src/widgets/MainWindow.h` (add `saveLastDocumentPath`, `loadLastDocumentPath`)

**Step 1: Add a read-modify-write helper**

Replace the write-from-scratch pattern in `saveDefaultLocation` with a helper that loads the existing JSON, merges new keys, and writes back. Add a file-local helper in `MainWindow.cpp`:

```cpp
static QJsonObject loadSettingsJson(const QString& path)
{
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly))
    {
        return {};
    }
    QJsonDocument doc = QJsonDocument::fromJson(file.readAll());
    return doc.isObject() ? doc.object() : QJsonObject{};
}

static void saveSettingsJson(const QString& path, const QJsonObject& json)
{
    QString cacheDir = QStandardPaths::writableLocation(QStandardPaths::CacheLocation);
    QDir().mkpath(cacheDir);

    QFile file(path);
    if (file.open(QIODevice::WriteOnly))
    {
        file.write(QJsonDocument(json).toJson());
    }
}
```

**Step 2: Refactor `saveDefaultLocation` to use read-modify-write**

```cpp
void MainWindow::saveDefaultLocation(double lat, double lng)
{
    QJsonObject json = loadSettingsJson(settingsFilePath());
    json["defaultLat"] = lat;
    json["defaultLng"] = lng;
    saveSettingsJson(settingsFilePath(), json);
}
```

**Step 3: Add `saveLastDocumentPath` and `loadLastDocumentPath`**

Declarations in `MainWindow.h` (private, static):

```cpp
static void saveLastDocumentPath(const QString& filePath);
static QString loadLastDocumentPath();
```

Implementation in `MainWindow.cpp`:

```cpp
void MainWindow::saveLastDocumentPath(const QString& filePath)
{
    QJsonObject json = loadSettingsJson(settingsFilePath());
    json["lastDocumentPath"] = filePath;
    saveSettingsJson(settingsFilePath(), json);
}

QString MainWindow::loadLastDocumentPath()
{
    QJsonObject json = loadSettingsJson(settingsFilePath());
    return json["lastDocumentPath"].toString();
}
```

**Step 4: Connect `filePathChanged` to save the path**

In `setupConnections`, add:

```cpp
connect(m_documentManager, &DocumentManager::filePathChanged,
        this, [this]() { saveLastDocumentPath(m_documentManager->filePath()); });
```

This fires on auto-save path assignment, Save As, Open, and New (which clears the path — saving empty string effectively clears the setting).

**Step 5: Build and verify**

Build the app. Open a document, close the app. Check `settings.json` — it should have `lastDocumentPath` alongside existing keys. The `defaultLat`/`defaultLng` values should be preserved (not wiped).

### Task 2: Auto-Load on Startup

**Files:**
- Modify: `src/widgets/MainWindow.cpp` (constructor)

**Step 1: Add auto-load to constructor**

After `setupConnections()` and before `initializeDefaultLocation()`, add:

```cpp
// Auto-load last document
QString lastPath = loadLastDocumentPath();
if (!lastPath.isEmpty() && QFile::exists(lastPath))
{
    m_documentManager->openDocument(lastPath);
}
```

This goes before `initializeDefaultLocation()` so the map center is set after the document is loaded (the map will center on families if present).

Note: `QFile::exists` check ensures silent fallback to new document if the file was deleted.

**Step 2: Call `fitAllFamilies` after auto-load**

If a document was loaded, fit the map to its families:

```cpp
QString lastPath = loadLastDocumentPath();
if (!lastPath.isEmpty() && QFile::exists(lastPath))
{
    m_documentManager->openDocument(lastPath);
    m_mapWidget->fitAllFamilies();
}
```

But `m_mapWidget` might not be ready yet — `setupUi()` creates it, so it exists, but the web view might not be loaded. Check if `fitAllFamilies` already handles this (deferred until page load). If so, calling it here is fine.

**Step 3: Build and verify**

Test sequence:
1. Open a document with families. Close app. Reopen — document should be loaded, map shows families.
2. Delete the file on disk. Reopen — app starts with empty document, no error.
3. Fresh install (no settings.json) — app starts normally.
4. Open doc A, then Open doc B, close app. Reopen — doc B loads (most recent).
5. New document, close app. Reopen — starts with empty document (path was cleared by New).
