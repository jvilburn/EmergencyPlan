Android and iOS versions of Ward Planning are planned, alongside the Windows and macOS desktop app (stated 2026-11-08).

**How to apply:** when weighing a design - sharing transport, background work, file handling, notifications, bundled tools - check it works on phones: iOS limits background execution and gives apps no access to SMS or iMessage; Android apps can send and read SMS with permissions Google Play reserves mostly for the default messaging app; either platform's app can read mail through IMAP or a provider API once the user signs in; files also arrive through the share sheet or "Open in". A choice that only works on a desktop needs that called out.
